はじめに

あや綴りは、ブラウザーで動く小説執筆アプリです。「小説家になろう」「カクヨム」「アルファポリス」用の原稿を、一つのエピソードの中に別々に持てます。インストールや登録はいりません。

最初の5分

  1. あや綴りを Chrome で開きます（おすすめは Chrome。Windows・Mac・iPhone・iPad・Android で使えます）。
  2. 「ファイル」→「新しい作品…」でメインの投稿サイトを選んで作品を作り、左上の「小説タイトル」に題名を入れます。
  3. 左の「＋ 話」でエピソードを足し、エピソードタイトルと本文を書きます。書いた内容は自動で端末に保存されます。
  4. 「設定」→「バックアップ」の「サーバへの自動バックアップ」で保存先を選びます（自動バックアップ）。

大切なこと　原稿は、使っている端末のブラウザーの中に保存されます。ブラウザーのデータを消したり端末が壊れたりすると、原稿も消えます。自動バックアップか「ファイル」→「保存…」で、端末の外にも残してください。

データの置き場所

  • 作品は端末のブラウザーの中に保存され、サーバーには送りません。
  • 外へ送るのは、自分で Google ドライブか OneDrive を使うと決めたときだけです。
  • 同じ端末でも、Chrome と Safari、ブラウザーとホーム画面のアプリでは、作品も設定も別々です。ふだん使う開き方を一つに決めておくと迷いません。

作品・章・エピソード

作品

  • 作る：「ファイル」→「新しい作品…」で、メインの投稿サイトを選びます。カクヨムを選んだときだけ、小見出しを使うかを聞かれます。使うとカクヨムだけの作品に、使わなければなろう・カクヨム・アルファを使う作品になります（要らないサイトは後で外せます）。
  • 開く・削除する：「ファイル」→「作品一覧…」。削除は、誤って消さないよう何段階か確認します。
  • 題名を変える：左上の「小説タイトル」を書き換えます。
  • メイン投稿先：左上で、使う投稿サイトの中から選びます。メインの原稿タブが先頭に並びます（投稿サイトと稿）。

章とエピソード

  • 「＋ 話」でエピソード、「＋ 章」で章を足します。「ファイル」→「新しい章…」「新しいエピソード…」では、入れる位置も選べます。
  • 章は使わなくてもかまいません。どの章にも入っていないエピソードは「未分類」として並びます。章を消しても、中のエピソードは「未分類」へ移るだけで消えません。
  • カクヨムだけを使う作品では、章はカクヨムと同じく大見出しと小見出しの2段になります。「⋯」→「大見出しにする」「小見出しにする」で切り替えます。大見出しのあとの小見出しは一段下げて並び、大見出しを折りたたむと中の小見出しもまとめて隠れます。
  • ほかのサイトも使う作品では、章は1段だけです（なろう・アルファと同じ）。大見出し・小見出しを使っていた作品にほかのサイトを加えると、どちらも章として並びます。区切りは消えないので、カクヨムだけに戻すと元の形に戻ります。
  • 「章あり／章なし」で、章ごとに分けて並べるか、全エピソードを一列に並べるかを選びます。
  • 並び順は、目次順・更新日時・作成日時・タイトル・本文の文字数・プロットの有無から選べ、「昇順／降順」で向きを変えます。
  • 章の「⋯」で、名前・プロット・上へ／下へ・削除ができます。エピソードの「⋯」で、上へ／下へ・ほかの章へ移す・削除ができます。上へ／下へは、並び順が「目次順」で、検索していないときに使えます。章名を押すと、章を折りたためます。
  • 目次の上の検索欄で、開いている側の原稿のタイトル・前書き・本文・後書きと、プロット・フリーメモを探せます。見つかった話を押すとその場所を選び、もう一度押すと次の場所へ移ります。

投稿サイトと稿

一つのエピソードの中に、小説家になろう・カクヨム・アルファポリスの原稿を別々に持ちます。自動では同じ内容になりません。左上の「メイン投稿先」で選んだサイトがメインです。

使う投稿サイト

  • 作品は、はじめは3サイトとも使います。左の「小説投稿サイト情報」の「使う投稿サイト」で、作品ごとに外せます。あとから足し直すこともできます。
  • 作品は変えずに、この端末で見せるタブだけを減らすときは、「設定」→「表示」の「対象小説サイト」を使います（表示）。
  • サイトを足すと、ほかのサイトの原稿からコピーするかを聞きます（書き方は変換します）。
  • サイトを外しても、その原稿は消えません。もう一度足すと元に戻ります。メイン投稿先は外せません。
  • 使わないサイトのタブ・欄は出ません。1サイトだけのときは、コピーのボタンも出ません。
  • 以前の版で作った作品は、3サイトを使う作品になります。データ形式を新しくする前の状態は、その作品のバックアップ版に「データ形式更新前（自動）」として残ります。

短編

「小説投稿サイト情報」の「短編」に印を付けると、エピソードが1つだけの作品として扱います。話を足すボタンや、なろう用のエピソードタイトルの欄は出ません（作品の題名を使います）。エピソードが2つ以上あるときは、短編にできません。

原稿を切り替える

中央の上の「なろう用」「カクヨム用」「アルファ用」タブで、編集する原稿を切り替えます。メインのタブが先頭で、「メイン」と出ます。切り替えると、ルビ・傍点の書き方や挿絵のボタンも、その投稿サイトに合わせて変わります。まだ何も書いていないタブには「（空）」と出ます。

稿

稿は、投稿サイトごとに別々に持ちます。稿に入るのは、その投稿サイトのタイトル・前書き・本文・後書きです（プロット・フリーメモは稿に関係なく共通）。

操作働き
稿の一覧で選ぶ今の内容をしまってから、選んだ稿に切り替えます。何も消えません。
＋ 稿を上げる今の稿を残したまま、同じ内容で次の番号の稿を作り、それを編集します。
最終稿にする表示している稿に【最終稿】の印を付けます。ほかの稿を「すべて削除」か「残す」かを選べます。
この稿を削除表示している稿を、確認のうえ削除します。最後の1つを削除すると、空の「第1稿」になります。

どの操作でも、ほかの投稿サイトの稿は変わりません。

サイト間のコピー

  • 原稿タブの横の「なろう→カクヨムにコピー…」のようなボタンで開きます。コピー元・コピー先のサイトは、使っているサイトの中から自由に選べます。
  • 開いているエピソードの、コピー元の今の稿だけをコピー先へコピーします。コピー元は変わりません。
  • コピー先は「新しい稿として追加」か「今の稿に上書き」を選びます。上書きは元に戻せません。
  • 変換後の本文を確かめてからコピーできます。
なろうカクヨムアルファポリス
ルビ|漢字《かんじ》（10文字まで）|漢字《かんじ》（親文字20文字・ルビ50文字まで）#漢字__かんじ__#
傍点|傍点《・・》《《傍点》》#傍点__・・__#
画像挿絵タグ <i1234567|12345>なし#__i_xxxxxxxx__#
前書き・後書きありなしなし
  • なろう → アルファでは、挿絵タグはみてみんの URL になります。アルファ → なろうでは、アルファの画像タグは 【ここに画像を挿入：識別子】 の目印になります。
  • カクヨムには挿絵がないので、カクヨムへコピーするときは画像を消します（画像だけの行は行ごと消します）。カクヨム → なろうでは、なろうの10文字を超えるルビに注意を出します（傍点は10文字ずつに分けます）。
  • 前書き・後書きのないサイトへコピーするときは、前書き・後書きはコピーしません。
  • 変換できない書き方は元のまま残し、注意を出します。文章が消えることはありません。

コピー先にすでに画像があるとき

コピー先の原稿にもう画像が入っているときは、コピーの前に「画像の対応」の画面が出ます。コピー先の画像タグはそのまま残り、文章だけが入れ替わります。コピー先に画像がなければ、この画面は出ず、今までどおりコピーします。カクヨムへのコピーでは出ません。

  • コピー元とコピー先の画像を、それぞれの前後1行ずつ（40字まで）といっしょに並べます。前後の文が似ているもの同士を、順番を崩さずに自動で組みます。
  • 前後の文が違う組には ⚠ が付きます。画像の数が違うときは、枚数の行に ⚠ が付きます。
  • 組み合わせがおかしいときは「対応を直す…」で、コピー元の画像ごとにコピー先の画像を選び直します。ほかの行で選んでいた画像を選ぶと、その行は「対応なし」になります。
画像コピー後
組んだ画像コピー先の画像タグのまま入ります
コピー元だけの画像今までどおり、変換した書き方（みてみんの URL・目印）で入ります
コピー先だけの画像タグのまま残し、コピー先ですぐ前にあった行と同じ行の次に入れます。その行がなくなっていれば、だいたい同じ位置に入れます（⚠ が付きます）

「キャンセル」を押すと、何もコピーしません。

作品の資料

左の目次の上にある項目で、作品全体の資料を開きます。どれもバックアップに入ります。

あらすじ・全体プロット

全体プロットの章は、目次の章と同じものです。全体プロットで、章のタイトルと章のプロットを書けます。

世界観・用語

登場人物

  • 表は分類ごとに分かれ、分類は自由に足せます。表の上の検索欄で、全項目か列を選んで探せます。
  • 所属：「＋ 所属」で世界観・用語の項目（国・組織など）を選び、立場も書けます。世界観・用語の側の「所属する人物」に自動で出ます。
  • 同一人物：名前を変えた同じ人物は別の行に書き、「＋ 同一人物」でつなげます。
  • 非公開：欄の中で先頭に「＃」を付けた行は非公開の扱いです。名前を「＃…」にすると、その行全体が公開用に出ません。
  • テキストに書き出す：列と行を選び、見出し形式・1人1行・表から形式を選んでコピーかファイルに保存します。「公開用」では「＃」の行を除きます。

メモ

作品全体のメモを、いくつでも作れます。「＋ メモを追加」で増やし、「◀」「▶」で並びを変え、「このメモを削除」で消します。エピソードごとのフリーメモとは別です。

小説投稿サイト情報

左の「小説投稿サイト情報」に、使う投稿サイトと、なろうの Nコード・作品 URL、カクヨムの作品 ID・作品 URL・キャッチコピー・タグ、アルファポリスの作品 ID・作品 URL を入れます。コードと URL は、片方を入れると、もう片方が自動で入ります（アルファの作品 URL には、「設定」→「投稿サイト」のユーザ ID が必要）。使っていないサイトの欄は出ません。入れなくても使えます。「使う投稿サイト」「短編」は投稿サイトと稿を見てください。

伏線

伏線を、張った話と回収した話に結び付けて記録します。話数は目次の並び順（第1話からの通し番号）で、並べ替えると今の話数で出し直します。

エピソードの「伏線」タブ

  1. 伏線を張った話で「＋伏線を追加」を押し、名前と内容を入れて登録します。話数は自動で入ります。
  2. 回収する話で「これまでの伏線（回収候補）」の「検索」を押すと、前の話までの伏線が出ます（最初は未回収・部分回収済みだけ）。
  3. その伏線の「この話（第N話）で回収を記録」で、部分回収か回収を選び、内容を書いて記録します。

状態（未回収・部分回収済み・回収済み）は、記録に合わせて自動で変わります。「取りやめ」は自分で選びます。

伏線一覧

  • 左の「伏線」で開きます。状態のチェック、検索、話の範囲で絞り込み、並べ替えができます。
  • 状態は表の中で選び直せます。話数を押すと、そのエピソードの伏線タブを開きます。
  • エピソードを削除しても伏線は消えず、「第N話（削除済み）」と出ます。

串刺し検索

  • 左の「串刺し検索」で、作品の資料と全エピソードをまとめて探します。対象はチェックで選びます。
  • 言葉はスペースで区切って複数入れられ、「AND（すべての言葉を含む）」か「OR（どれかを含む）」を選びます。"…" か 「…」 で囲むと、スペースを含めて1語になります。
  • 結果を押すと、その場所を開いて当たった文字を選びます。稿は今の稿だけを探します。

保存とバックアップ

しくみ場所働き
自動保存端末の中書いた内容を、入力が止まると自動で保存します。上のバーに「端末に保存済み」と出ます。
変更履歴と復元ポイント端末の中作品全体の過去の状態を残し、そこへ戻せます。

サーバへの自動バックアップ

  1. クラウドを使うときは、先に「設定」→「クラウド」でクラウドを選び、ログインします（クラウドの準備）。
  2. 「設定」→「バックアップ」の「保存先（この端末）」で、「フォルダ」か「クラウド」を選びます。
  3. 「フォルダを選ぶ…」で、保存するフォルダを選ぶか作ります。選んだフォルダに直接保存します。
  4. 「ファイル名の先頭（プレフィックス）」「入力が止まってから」「残す件数」を決めます。
保存先使える端末
フォルダパソコンの Chrome・Edge、Android の Chrome（機種によっては使えません）。ネットワークドライブや、パソコン版 OneDrive の同期フォルダも選べます。
クラウドすべての端末。iPhone・iPad はこちらを使います。
  • 保存するのは、画面を離れるとき（別のアプリに切り替える・閉じる）と、入力が「入力が止まってから」の時間（はじめは30分）止まったときです。
  • 中身が本当に変わったときだけ保存します。空白を入れて消しただけなど、前に保存したときと同じ中身なら保存しません。ほかの端末のバックアップを読み込んだり、バックアップから復元したりしただけでも保存しません（そのあと書き換えたら保存します）。
  • 入るのは、前に保存したときから中身が変わったエピソードです（開いているエピソードではありません）。作品資料も、変わっていれば一緒に入ります。
  • 残す件数を超えると、この端末が作った古いものから消えます。ほかの端末のものは消しません。
  • ファイル名は「内容_日時」の形で、自動バックアップには端末名（例：@Win_）が付きます。

ほかの端末で続きを書く

  1. すべての端末で、同じクラウド・同じアカウント・同じフォルダを選びます。プレフィックスは端末ごとに変えます。
  2. ほかの端末の新しいバックアップがあると、起動したときや保存の前に知らせが出ます。一覧から読み込むものを選びます。
  3. 読み込むときは、作品ごとに「上書き」か「新小説」（新しい作品として追加）を選びます。

同時に書ける同期ではありません。一方で書いたら保存し、もう一方で読み込んでから続けます。あとで確かめるときは、「設定」→「バックアップ」の上に出る「⚠ 他の端末の更新を確認」を押します。

バックアップファイルの管理と復元

  • 「バックアップファイルを管理…」で、保存先のバックアップの一覧を開きます。日時の順、内容（環境・作品全体・作品情報・エピソード）、端末で絞り込めます。
  • ファイルを選ぶと中身を確かめられ、選んだものだけを読み込めます。削除もできます。
  • 読み込む前に、変わる作品ごとに復元ポイント「バックアップ読み込み前（自動）」を作ります。
  • 「⚙ 環境」を読み込むときは、この端末の設定に「まとめる」か、バックアップの設定で「置き換える」かを選びます。

変更履歴と復元ポイント

  • 書いている間は10分ごとと画面を閉じるときに、作品全体の状態を端末の中に残します。残す数は「自動履歴の保存数」（1〜500件）。
  • 大きく書き直す前やインポートの前は、「＋ 復元ポイントを作成…」で名前を付けて残すと安心です。手動の復元ポイントは自動では消えません。
  • 一覧から戻したり、削除したりできます。この端末の中だけに残り、バックアップには入りません。

バックアップに入るもの・入らないもの

  • 入る：作品（本文・稿・プロット・メモ・伏線・章・資料・活動報告など）。「環境設定を含める」を選ぶと、表示・ひな型・リンク・投稿サイトのアカウント・TXT インポートの条件なども入ります。
  • 入らない：クライアント ID、ログインの情報（アクセストークンなど）、変更履歴と復元ポイント。自動バックアップの保存先・プレフィックスなど、端末に結び付く設定は、読み込んでも置き換えません。

TXT インポート

「小説家になろう」「アルファポリス」から出力した TXT と、「カクヨム」のバックアップ ZIP を、章とエピソードに分けて取り込みます。「設定」→「インポート」→「TXT をインポート…」で開きます。

  1. 「インポート元」（小説家になろう／カクヨム／アルファポリス）、「取り込み先」（新しい作品／既存の作品）、「文字コード」を選びます。なろうはなろう用、カクヨムはカクヨム用、アルファはアルファ用の原稿に取り込みます。新しい作品へ取り込むと、取り込んだサイトがメイン投稿先になります。既存の作品へ取り込むと、取り込んだサイトがその作品の「使う投稿サイト」に入ります。
  2. 「ファイルを選ぶ…」で TXT か ZIP を選びます。いつも端末のファイル選択画面が開きます（「設定」→「ファイル」とは関係ありません）。ZIP は中の TXT を1つ選びます。
  3. アルファポリスは、続いてタイトル一覧（ファイルか貼り付け）を入れます。
  4. 「区切り確認」で、章・話の区切りを確かめます。違うところは行ごとに直せます。
  5. プレビューで、章・話・文字数・既存の話との関係を確かめ、「取り込む」を押します。
  • なろうの短編は、TXT の中身から自動で見分け、1話として取り込みます。
  • カクヨムは、作品の管理画面から出力したバックアップの ZIP（about.txt と episode_0001.txt などが入ったもの）をそのまま選びます。区切り確認はなく、すぐにプレビューになります。プレビューで、キャッチコピー・タグ・紹介文を取り込むか、短編として取り込むかを選べます。
  • カクヨムの目次の大見出し・小見出しは、そのまま取り込みます。新しい作品として取り込むとき、小見出しがあればカクヨムだけの作品に、なければなろう・アルファも使える作品になります（自動で決まります）。ほかのサイトも使う作品へ取り込むと、大見出し・小見出しは章として並びます。下書きの話も取り込めます（プレビューの「注意」に「下書き」と出ます）。
  • 区切りの条件や書式の編集は、区切り確認の画面の「詳しい設定」を開くと出ます。
  • 既存の作品へ取り込むときは、TXT の話を、取り込み先の話とタイトルで組み合わせます。ほかのサイトのタイトルでも探します。
  • ファイルの話の順番が今の目次順と違うときは、「目次順を ZIP（TXT）の順に並べ替える」が出ます。選ぶと、章の中の順番をファイルに合わせます（目次順は3サイト共通です）。原稿が同じで順番だけ違うときも取り込めます。
  • 取り込み方は「置き換える」（今の話は残し、組み合わせた話の原稿を入れ替える）、「新しい稿として追加」、「作り直す」（今の話と章をすべて消してから入れる）から選びます。
  • 組み合わせられなかった話は、行ごとに「取り込み先を指定…」「新しい話として追加」「スキップ」を選びます。「取り込み先を指定…」では別の画面が開き、取り込み先の話を一覧から選びます（タイトルで絞り込めます）。選んだ行は、絞り込みを選び直すまで一覧に残ります。
  • 組み合わせた話の今の原稿に画像があるときは、画像のタグを残したまま文章だけを入れ替えます。画像は前後の文で組み合わせ、枚数が同じで前後の文も同じ話は自動で入れます。枚数が違う・前後の文が違う話だけ、「取り込む」を押したあとの「画像の確認」に出ます。「確かめる…」で、サイト間のコピーのときと同じ「画像の対応」の画面が開き、組み合わせを直せます。カクヨムの取り込みでは確かめません。
  • 取り込む前の状態はバックアップ版に残ります。途中の作業も残り、次に開くと続けられます（カクヨムの ZIP は、もう一度選び直します）。
  • 「設定」→「投稿サイト」にアカウントを入れておくと、TXT の作者情報と違うときに確認が出ます（なろう・アルファ）。

クラウドの準備

Google ドライブか OneDrive を使うときだけ、最初に1回行います。自分専用のアプリを登録し、そのクライアント ID をあや綴りに入れます。サーバーやクライアントシークレット（秘密の鍵）は使いません。入力も公開もしないでください。

Google ドライブ

  1. Google Cloud Console でプロジェクトを作り、Google Drive API を有効にします。
  2. 「Google Auth Platform」で次を設定します。
    • ブランディング：アプリ名・サポートメール
    • 対象：「外部」・「テスト中」のまま、テストユーザーに自分の Google アカウント
    • データアクセス：スコープ https://www.googleapis.com/auth/drive.file
  3. クライアントで「ウェブ アプリケーション」を作り、次を登録します。
    欄値
    承認済みの JavaScript 生成元https://tri-ton-novel.github.io
    承認済みのリダイレクト URIhttps://tri-ton-novel.github.io/novel-editor/（最後の / まで同じに）
  4. あや綴りの「設定」→「クラウド」で「Google ドライブ」を選び、クライアント ID（…apps.googleusercontent.com）を入れて「Google ドライブにログイン」を押します。
  • ログインのとき「Google はこのアプリを確認していません」と出ます。自分で作ったアプリなので、「詳細」から進んで許可します。
  • 1回のログインは約1時間です。アプリが「テスト中」の間は、約7日ごとにログインし直します。
  • drive.file の権限では、あや綴りで作ったファイル・フォルダだけが見えます。保存先のフォルダは、あや綴りの「＋ 新しいフォルダ」で作ってください。

OneDrive

  1. Microsoft Entra 管理センターに、OneDrive を使う Microsoft アカウントでサインインします。
  2. 「アプリの登録」→「新規登録」で、次のように登録します。
    • 名前：自由（例：あや綴り）
    • サポートされているアカウントの種類：「任意の組織ディレクトリ内のアカウントと個人用の Microsoft アカウント」
    • リダイレクト URI：プラットフォームは「シングルページ アプリケーション（SPA）」、URI は https://tri-ton-novel.github.io/novel-editor/
  3. 「API のアクセス許可」→「アクセス許可の追加」→「Microsoft Graph」→「委任されたアクセス許可」で、Files.ReadWrite.AppFolder と offline_access を追加します。
  4. 「概要」の「アプリケーション（クライアント）ID」をコピーします（オブジェクト ID やテナント ID ではありません）。
  5. あや綴りの「設定」→「クラウド」で「OneDrive」を選び、ID を入れて「OneDrive にログイン」を押します。
  • ログインは Microsoft のページへ移って行い、終わるとあや綴りに戻ります。約1日続きます。
  • 使えるのは、OneDrive の「アプリ」（Apps）の中にできる、登録したアプリの名前のフォルダの中だけです。

「⚠ （クラウド名）にログイン」が出るログインが切れています。押してログインし直します
前の内容に戻したい「設定」→「バックアップ」の「変更履歴と復元ポイント」から戻します
