最初の5分で始める

初めて使う場合は、次の順に進めると執筆とバックアップをすぐに始められます。

  1. Chromeであや綴りを開きます。必要ならホーム画面またはデスクトップへPWAとして追加します。
  2. ファイルから新しい作品を作り、小説タイトルを入力します。
  3. ＋章と＋話で目次を作り、エピソードタイトルと本文を入力します。
  4. 設定 → バックアップで、Google Drive、OneDrive、または端末フォルダーを保存先に設定します。
  5. 編集エピソード保存を押し、表示中のエピソードを端末外へバックアップします。

重要　原稿は端末のブラウザー内に保存されます。ブラウザーのデータ消去や端末故障に備え、端末外へのバックアップを設定してください。

目的から探す

本文を書きたい章や話を増やしたい 以前の稿を残したい投稿サイトのTXTを読みたい 伏線や設定を探したい別端末で続きを書きたい

基本画面と執筆

画面は、左の作品情報と目次、中央の本文、右のプロットとメモを中心に構成されています。画面幅が狭い端末では、必要な領域を切り替えて表示します。

場所役割
上段ファイル、戻す、やり直す、保存状態、リンク、設定
左側小説タイトル、あらすじ、作品資料、章とエピソード
中央エピソードタイトル、本文、前書き、後書き
右側プロット、フリーメモ、伏線

本文を書く

  1. 左の目次から編集するエピソードを選びます。
  2. エピソードタイトルと本文を入力します。内容はブラウザー内へ自動保存されます。
  3. 必要に応じて、ルビ、傍点、挿絵、記号、字下げ、検索、置換を使います。
  4. 端末外にも残すときは、編集エピソード保存を押します。

保存状態　上段に「端末に保存済み」と表示されれば、ブラウザー内への保存は完了しています。編集エピソード保存は、表示中のエピソードを設定済みのバックアップ先へ保存する操作です。

作品 章 エピソード

新しい作品を作る

  1. 上段のファイルを開きます。
  2. 新しい作品を選びます。
  3. 作成された作品を開き、小説タイトル、あらすじ、全体プロットなどを入力します。

章とエピソードを管理する

  • ＋章で章を追加し、＋話でエピソードを追加します。
  • 章ありでは章とその中の話をまとめて表示し、章なしでは全エピソードを一覧にします。
  • 並び順はファイル順、タイトル、更新日時、作成日時、文字数、プロットの有無から選べます。
  • 章やエピソードの右にある操作ボタンから、名称変更、移動、削除などを行います。

本文とプロットを並べる

本文を見ながら、その回の構成、修正事項、思いつきをプロットとフリーメモへ書けます。境界をドラッグすると表示領域を変えられます。

  • 他の話からで、別のエピソードのプロットまたはフリーメモをコピーできます。
  • 各領域は折りたたみ、最大化、検索、全て選択、コピーに対応します。
  • 伏線タブでは、その話で張る伏線と前の話までの回収候補を管理できます。

投稿サイト別の原稿と稿

一つのエピソードの中に、なろう用とアルファポリス用の原稿を別々に保存できます。両方の内容が同じである必要はありません。

原稿を切り替える

  1. エピソード上部のなろう用またはアルファ用を選びます。
  2. 選んだ投稿サイト用のタイトル、本文、前書き、後書きを編集します。
  3. メイン投稿先を変更すると、コピーの向きと案内も切り替わります。

稿を残して改稿する

  • ＋稿を上げるで、現在の稿を残したまま次の稿を作ります。
  • 稿の一覧から以前の稿を選び、内容を確認できます。
  • 稿の削除はなろう用とアルファ用で独立しています。

別サイト用へコピーする

コピーされるのは、現在表示している一つの稿だけです。コピー時には、ルビ、傍点、挿絵などの記法をコピー先に合わせて変換できます。

活動報告を作る

活動報告はエピソードごとに保存します。Xの投稿文となろう活動報告のタイトルと本文を同じ画面で作成できます。

  • 設定のひな型で、話数、エピソード名、作品URLなどを自動挿入できます。
  • 投稿先を開くボタンは、設定のリンクに登録したページを開きます。
  • 投稿文はコピーして、投稿サイト側へ貼り付けます。

作品資料

作品全体の資料は、左側のあらすじ、全体プロット、世界観 用語、登場人物、メモから開きます。

世界観と用語

  • 国、組織、種族、地名、道具などの分類を作れます。
  • 検索と分類で絞り込み、必要な行と列だけをテキストへ書き出せます。
  • 先頭に＃を付けた行は、公開用の書き出しから除外できます。

登場人物

  • 名前、読み、性別、年齢、自己人称、立場、性格、外見などを管理できます。
  • 世界観 用語の項目を人物の所属として結び付けられます。
  • 改名や別名は、同一人物として複数の行を関連付けられます。

伏線と串刺し検索

伏線を登録して回収する

伏線を張ったエピソードに登録し、後のエピソードで部分回収または回収を記録します。状態は自動で変わります。

  1. エピソードのプロット メモ 伏線タブを開きます。
  2. 伏線を追加し、名前、内容、キーワードを入力します。
  3. 回収する話で、これまでの伏線から対象を探します。
  4. 部分回収または回収を記録します。

作品全体から探す

串刺し検索では、作品資料と全エピソードをまとめて検索します。AND検索とOR検索を選べます。

  • あらすじ、全体プロット、世界観、登場人物、メモ、伏線を検索できます。
  • タイトル、本文、前書き、後書き、プロット、フリーメモ、活動報告も対象にできます。
  • 結果を押すと、該当する入力欄を開きます。

ファイル保存

ファイルメニューの保存は、選んだ内容を一つの .ayabackup ファイルへまとめて、任意の場所へ保存する操作です。持ち出し用や長期保管用に使えます。

バックアップパックを作る

  • 環境設定を含めるでは、表示設定、ひな型、リンク、アカウント、TXTインポート条件などを含めます。アクセストークンは含めません。
  • 全作品、作品全体、選んだエピソードから範囲を選びます。
  • エピソードには、両投稿サイトの全稿、本文、前書き、後書き、プロット、フリーメモ、活動報告が含まれます。
  • 読み込み前に内容を確認して、作品または環境を選んで復元できます。

プレーンテキスト

操作用途
インポート エピソードエリアへUTF-8またはShift JISのテキストを現在のエピソードへ取り込む
エクスポート エピソードから現在表示している側の原稿を書き出す
エクスポート 全エピソード作品の全エピソードを書き出す

TXT一括インポート

設定のインポート なろう アルファから、投稿サイトで出力したTXTを章とエピソードに分けて登録できます。TXTを含むZIPも選べます。

書式あり なろう系

  1. ダウンロードしたTXTまたはZIPを指定します。
  2. ZIPの場合は、中の一覧からTXTを一つ選びます。
  3. 章とエピソードの区切り、削除する見出し、文字コードを確認します。
  4. プレビューでタイトルと取り込み先を確認し、取り込みます。

書式なし アルファ系

  1. 物語本文のTXTを選びます。
  2. 次へ進み、タイトル一覧ファイルを選ぶか一覧を貼り付けます。
  3. タイトル一覧の読み方を簡易書式設定で作成します。
  4. プレビューで章、話、対応先を確認して取り込みます。

取り込み先　新しい作品のほか、既存作品のなろう用またはアルファ用へ対応付けられます。対応する話がない場合は、確認画面で「対応なし」に絞り込み、取り込み先を手動指定できます。

バックアップ

最新状態はブラウザー内に自動保存されますが、ブラウザーのデータを消すと失われます。端末外への自動バックアップを設定してください。

種類役割
端末内保存入力中の最新状態をブラウザー内へ自動保存
変更履歴と復元ポイント端末内に残る履歴から以前の状態へ戻す
自動バックアップクラウドまたは端末フォルダーへ保存し、端末間共有にも使う
ファイルへ保存選んだ内容を一つの .ayabackup として任意の場所へ保管

自動バックアップを設定する

  1. 設定のクラウドで、なし、Google Drive、OneDriveのいずれかを選びます。
  2. クラウドを使う場合は、クライアントIDを入力してログインします。
  3. 設定のバックアップで保存先を選びます。PCのChromeとEdgeでは端末フォルダーも選べます。
  4. 保存間隔、残す件数、ファイル名のプレフィックスを設定します。
  5. 複数端末で共有するときは、すべての端末で同じクラウドと同じフォルダーを選びます。

他の端末の更新を読み込む

  • 別端末の新しいバックアップが見つかると確認画面が表示されます。
  • 作品は上書き、または新しい作品として追加できます。
  • 環境は、この端末の設定へまとめるか、バックアップで置き換えるかを選びます。
  • 意図的に過去の履歴を選んだ後は、それ以前の履歴を新しい更新として自動確認しません。

クラウド設定

使うクラウドと接続IDはクラウドタブで設定し、ファイルとバックアップの保存先はそれぞれのタブで選びます。

Google Drive

  • Google CloudでDrive APIを有効にし、ウェブアプリケーションのクライアントIDを作成します。
  • 生成元とリダイレクトURIに、利用するあや綴りの公開URLを登録します。
  • スコープは drive.file を使用します。

OneDrive

  • Microsoft Entraでシングルページアプリケーションを登録します。
  • 委任されたアクセス許可に Files.ReadWrite.AppFolder と offline_access を設定します。
  • アプリケーション クライアントIDをあや綴りへ入力します。

クライアントシークレットは入力しません。クラウド事業者の画面は変わることがあるため、READMEの最新手順も確認してください。

表示を自分仕様にする

表示設定は端末ごとに保存されます。パソコンでは詳細表示、スマートフォンでは簡易表示というように、使うボタンと入力欄を調整できます。

  • 使う表示で簡易または詳細を選び、表示項目を個別にオン オフします。
  • 作品情報、エピソード欄、コピー、全て選択、貼り付けなどを細かく選べます。
  • 本文を最大化したときに表示するルビ、傍点、検索なども選べます。
  • 説明ラベルをまとめて非表示にすると、入力欄を広く使えます。

安全な運用

  • 執筆前に自動バックアップの保存先を確認します。
  • 大きな変更やTXTインポートの前に、バックアップパックを作ります。
  • バックアップ管理で、日時、端末、内容を定期的に確認します。
  • 重要な節目では、クラウドとは別の場所にも .ayabackup を保存します。

より詳しいクラウド登録手順や機能の補足は、READMEとdocs内の既存マニュアルを参照してください。
