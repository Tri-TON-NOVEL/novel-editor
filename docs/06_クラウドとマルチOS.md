# Phase 9〜10 Google ドライブの保存先・マルチ OS

## Google ドライブの保存先フォルダ（No.23）
- 「設定」→「クラウド」に、現在の保存先フォルダの名前と ID を表示。
- 選び方：
  - **Google Picker**（API キーを設定したとき）：既存のフォルダを選ぶ。`drive.file` 権限のまま、選んだフォルダに保存できる。
  - **新しいフォルダを作って使う**：名前を付けてマイドライブに作る（API キー不要）。
  - **自動のフォルダに戻す**：従来どおり「小説エディター」フォルダを自動で作って使う。
- 保存先は端末ごと（localStorage `novel-editor:gdrive.folder`）。
- 保存先を変えても、すでに保存したファイルは移動しない。連携済みの作品は同じファイルを更新し続ける。
- 新しく作るとき、同じフォルダに同じ名前のファイルがあれば：同じ作品（`appProperties.workId` が一致）ならそのファイルを更新、別の作品なら上書きせず「名前 (2).json」で作る。
- 更新は Drive の1回の要求で中身を差し替えるため、通信に失敗しても元のファイルは残る。
- OAuth のトークンは作品 JSON・ログに保存しない（メモリ上だけ）。権限は `drive.file` のまま。
- **未検証**：Google のクライアント ID がないため、実際の Drive への保存・Picker はこちらで動かしていない。

## 作品の識別
- `workId`（v3 で追加）で同じ作品かを判断する：ファイル・Drive からの読込（`importContent`）、Drive の同名ファイルの照合。
  workId のない旧データは、従来どおりタイトルと作成日時で照合する。

## 複数タブの競合（§7）
- 同じ端末で同じ作品を2つのタブで開いて編集すると、後から保存した方で上書きされる。
  BroadcastChannel で保存を知らせ合い、もう一方のタブに「⚠ 別のタブでも編集中」と警告を出す。

## 保存状態の表示（§7）
上部の状態欄に「保存中…」「保存済み HH:MM」「⚠ 保存に失敗しました」（失敗時は理由をトーストでも表示）。

## スマートフォン・タブレット（No.25〜27）
| 項目 | 対応 |
|---|---|
| 1カラム | 900px 未満で目次はドロワー、本文とプロット・メモはタブで切り替え |
| 600px 未満 | 上部ボタンを1つの流れに、戻す／やり直すは記号だけ、コピー先ボタンは短い表記。エピソード画面は画面ごとスクロールし、本文は高さ 55% を確保 |
| タップ領域 | 指で触る端末（`pointer: coarse`）ではボタン・入力欄を 44px 以上（小さい道具ボタンは 40px） |
| 横スクロール | ページ全体の横スクロールなし（375px 幅で確認）。表は狭い画面でカード表示 |
| キーボード | 最大化中は visualViewport に合わせて、キーボードに隠れない範囲に広げる |
| セーフエリア | `env(safe-area-inset-*)` を全体・最大化・全画面のインポート画面に適用 |
| ズーム | 禁止しない（viewport に `user-scalable=no` などを付けていない）。入力欄は 16px 以上でiOS の自動拡大を防ぐ |
| 戻る操作 | 最大化中・インポート画面では、戻る操作でそれを閉じるだけ（履歴を1つ積む） |
| ダイアログ | 小さい画面でも決定ボタンの段は下に固定して常に見える。中身はスクロール |
| ファイル | 標準のファイル選択だけで使える（`showDirectoryPicker` を必須にしない。自動バックアップのみ PC 限定） |
| ドラッグ | ドラッグでしかできない操作はない（境目のドラッグは PC の幅だけ。章・話の移動はボタンとプルダウン） |
| 長い名前 | 目次の章名・話名は省略表示し、`title` で全文を確認できる |
