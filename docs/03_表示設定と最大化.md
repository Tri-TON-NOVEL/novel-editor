# Phase 3〜4 フリーメモ・表示設定・最大化

## フリーメモ（No.05）
- `episodes[].freeMemo`。なろう用・アルファ用で共通（サイト間コピーの対象外）。プロットとは別の欄。
- 入力・コピー・最大化・表示切替・自動保存・版・ファイル／Drive 保存の対象。

## 表示・ボタン設定（No.14〜16）— 端末ごと（localStorage `novel-editor:ui`）
| キー | 対象 |
|---|---|
| `show.foreword / afterword / plot / memo` | 入力欄の表示（タイトル・本文は常に表示） |
| `copy.ep-title / body / foreword / afterword / plot / free-memo / main-to-sub` | コピーボタン |
| `max.title / body / foreword / afterword / plot / memo` | 最大化ボタン |

- 値が `false` のときだけ隠す（未設定は表示）。チェックした時点で反映・保存。
- 隠すのは CSS（`body.hide-*`）だけで、値の削除・自動保存の停止はしない。
- プロットとフリーメモを両方隠すと、右側の欄と境目を消して本文を全幅にする。

## 最大化（No.17）
- 各欄の「⤢」で、その欄を画面いっぱい（セーフエリアの内側）に広げる。他の欄・ツールバーは隠れる。
- 右上の「⤡ 元に戻す（Esc）」、Esc キー、ブラウザ／Android の「戻る」で元に戻す（最大化時に履歴を1つ積む）。
- 同じ入力欄を CSS で広げるだけなので、内容・カーソル・選択範囲・スクロール位置はそのまま。
- 狭い画面でタブに隠れている欄は、そのタブを開いてから広げる。前書き・後書きは開いてから広げる。
