# Phase 7〜8 TXT 一括インポート

「設定」→「インポート／エクスポート」→「TXT をインポート…」（全画面）。解析は `js/importer.js`（純粋関数）、画面は `js/importui.js`。

## 手順
1. **ファイル**：取り込む原稿（なろう用／アルファ用）、取り込み先（新しい作品／既存の作品）、TXT、文字コード。
2. **区切り**：区切りの条件で自動検出 → 全文を見ながら手動で修正（行の「−」で 話 → 章 → 解除）。右に検出した章・話と文字数。
3. **プレビュー**：作品名、章数・話数・文字数、前書き・後書き・画像タグの数、注意、先頭の未解析の行、既存との重複候補。行ごとに取り込む／外す、扱い（上書き・別の話として追加・スキップ・取り込み先を指定）。
4. **取り込む**：追加・上書き・スキップの件数を最終確認してから確定。

確定するまで作品は変更しない。確定は作品の複製の上で全部の変更を組み立ててから一度に保存する（途中で失敗しても中途半端にならない）。
既存の作品に取り込むときは、確定前の状態を作品全体のバックアップ版「インポート前（自動）」に残す。
取り込むのは選んだサイト側の原稿（タイトル・本文・前書き・後書き）だけ。もう一方の原稿・プロット・フリーメモは変わらない。
上書きでは、取り込む側の前書き・後書きが空なら既存の前書き・後書きを残す。

## 文字コード（No.13）
- 自動判定：BOM があれば UTF-8 → UTF-8 として正しく読めれば UTF-8 → それ以外は Shift_JIS（CP932）。判定の確かさ（高い・ふつう・低い）を表示。
- 手動で切り替えると、その場で読み直す。
- 読めない文字（�）があれば、個数と行番号を赤枠で表示する（そのまま取り込むと � が入ることを明示）。
- 50MB を超えるファイルは読み込まない。

## 区切りの条件（No.09）
| 項目 | 値 |
|---|---|
| 区切り | 話・章・前書き／後書き の3種類（それぞれ有効／無効） |
| 検索位置 | 行頭（字下げの空白は無視）／行内 |
| 判定方法 | 完全一致／前方一致／正規表現 |
| 区切り行 | タイトルにする（前方一致の記号は外す）／除いて次の行をタイトルにする |
| 保存 | 名前を付けて保存・削除（端末ごと、`novel-editor:importPresets`） |

正規表現は入力のたびに検査し、誤りはその場で赤く表示する。入れ子の繰り返し（`(a+)+` など）と 200 文字を超える条件は受け付けない。
1行の判定に使うのは先頭 400 文字まで、全体で3秒を超えたら止める（画面が固まらないように）。

前書き・後書きの区切り行が2つ以上あれば「最初の区切りより前＝前書き、最後の区切りより後＝後書き」、1つだけなら後ろを後書きとし、注意を出す。

### 組み込みのプリセット（サンプル入手後に調整）
- なろう：「第○話」「第○章」の行（正規表現）。前書き・後書きの区切りは「＊＊＊」などの記号行（初期は無効）。
- アルファ：行頭「◆」でエピソード。
- 「Episode 1」形式。

## 見出し（【…】など）の扱い（2026.10.21-3.1 で追加）
なろうのダウンロード TXT には `【エピソードタイトル】` `【本文】` `【リアクション】` などの見出しと、
`------------------------- エピソード2開始 -------------------------` の区切り線が入っている。

| 設定 | 内容 |
|---|---|
| 見出しの行を処理する | 有効／無効 |
| 見出しとみなす行 | 正規表現（既定 `^【[^】]+】$`。前後の空白は無視） |
| 既定の扱い | 条件に合う見出しの扱い |
| 見出しごとの扱い | 見出しの文字列（完全一致／前方一致／正規表現）と扱い。既定の扱いより優先 |

扱いの種類：**この行だけ消す**／**この行から塊ごと消す**（次の見出しか次の話の区切りまで）／**塊を前書きにする**／**塊を後書きにする**（どちらも見出しの行は消す）／**残す**。

- 行を消してからタイトルを判定する。区切り線を「区切り行を除き次の行をタイトルに」にすると、`【エピソードタイトル】` を飛ばしてその次の行がタイトルになる。
- 全文の一覧で、消える行は取り消し線（塊は斜線の背景）、前書き・後書きになる行は破線で示し、行の横に「消す／前書き／後書き」と表示する。上に消す行の数を出す。
- 見出しで前書き・後書きが分かるときは、それを使う（前書き・後書きの区切り行の推測より優先）。
- 解析は `importer.js` の `headingMask`（純粋関数）。

### 既定の条件
- 組み込みのプリセット「なろう：ダウンロード TXT（区切り線と【見出し】）」を最初の既定にした：
  - 話の区切り：`^-{3,}エピソード[0-9]+開始-{3,}$`（空白は自由）、区切り行を除き次の行をタイトルに
  - 見出し：既定は「この行だけ消す」、`【リアクション】` は塊ごと消す、`【前書き】`・`【後書き】` は前書き・後書きへ
- 「この条件を既定にする」で、次にインポートを開いたときの条件を変えられる（端末ごと `novel-editor:importDefaultPreset`）。
  選んだ条件から変えているときは、名前を付けて保存してから既定にする。既定の条件はプルダウンに「（既定）」と出る。

## 手動の区切り（No.10）
- 自動検出とは別に保持し、太枠で表示する。自動検出と同じ指定になったら手動の印は外す。
- 再検出のとき「手動で指定した区切りを残す」が既定でオン。オフにして検出し直すときは確認を出す。

## 重複の判定（No.12）
優先順：
1. 以前の取り込みで保存した取込キー（同じサイト側の本文の指紋 `importKeys[サイト]`）が一致
2. 本文の指紋（空白の違いは無視）が一致
3. タイトル（と章名）が一致
4. 話数を除いたタイトルが一致（例：「第1話　筆になった朝」と「筆になった朝」）

既定の扱い：同じ本文 → スキップ。同じ／似たタイトル → 取り込み先のその原稿が空なら上書き（空を埋めるだけ）、内容があればスキップ。新しい話 → 追加。
判定が確実でないものを自動で上書きすることはない。

## 途中の作業の保存・再開（オプション C）
ファイル名・デコード後の本文・条件・手動の区切り・手順を IndexedDB `meta.importSession` に自動で残す。次に開くと「続きから再開」「破棄する」を選べる。確定したら消す。
再開時は元のバイト列を持たないため、文字コードを変えるにはファイルを選び直す。

## 未確認・今後
- なろうの「通常 TXT」「下書き TXT」、アルファポリスの TXT の**実ファイル形式は未確認**。サンプルを入手したらプリセットと前書き・後書きの判定を調整する。
- フリーメモに当たる部分の自動抽出は、形式が分からないため未対応（取り込み後に手で移す）。
