# Phase 0 現状調査（改修前 2026.10.19-12）

仕様書 Ver3.0 §13「実装前に確認すべき事項」に対する調査結果。

## 1. 構成
| 項目 | 現状 |
|---|---|
| フレームワーク | なし（素の HTML / CSS / ES Modules） |
| 状態管理 | `js/app.js` のモジュール変数（`project`, `epIndex`, `view`）。入力のたびに `project` を直接更新し、600ms 後に IndexedDB へ保存 |
| PWA | `manifest.webmanifest` + `sw.js`（ネット優先・キャッシュ予備、`cache: 'no-cache'`） |
| 対象ブラウザ | Chrome / Edge / Safari（Windows・macOS・iPadOS）。File System Access API は Chrome/Edge のみ、他は代替あり |
| 版管理 | Git なし → 各 Phase の前に `I:\Programs\NovelEditor_snapshots\` へ ZIP スナップショット |

## 2. 保存データ（IndexedDB `novel-editor` v4）
| ストア | 内容 |
|---|---|
| projects | 作品（下記 JSON の `project` に `id`・`links` を加えたもの） |
| versions | 版。`kind: 'episode'`（エピソードの版）／`'project'`（作品全体のバックアップ版） |
| meta | 自動バックアップ先フォルダのハンドル |
| works | v1 旧形式（起動時に projects へ移行済み） |

端末設定は localStorage（`novel-editor:*`）。表示設定・リンク・ひな型・並び順・クラウドのクライアントID など。

## 3. 作品 JSON（ファイル／Google ドライブ保存）現行 version 2
```json
{ "format": "novel-editor", "version": 2, "project": {
  "title", "site": "narou|alpha", "narouUrl", "alphaUrl", "synopsis",
  "episodes": [{ "id", "title", "foreword", "body", "afterword", "plot", "createdAt", "updatedAt" }],
  "chapters": [{ "id", "title", "plot" }],
  "world": { "categories": [{ "id", "name" }], "items": [...] },
  "characters": { "categories": [...], "items": [...] },
  "reports": { "x", "narouTitle", "narouBody" },
  "createdAt", "updatedAt" } }
```
- version 1（`title/body/plot` のみ）も読込可。`memo` は章「作品メモ」へ移行済み。
- `id`・`links` は端末ローカル（ファイルには含めない）。**作品を端末間で識別する安定 ID はない**（タイトル＋作成日時で照合）。

## 4. 確認事項への回答
| §13 の項目 | 調査結果 | 方針 |
|---|---|---|
| 全体プロットの章 | `project.chapters[{id,title,plot}]` が既に独立配列。エピソードとの関連はなし | この配列をそのまま「章」に昇格（A方式）。エピソードに `chapterId` を追加。二重保存しない |
| エピソードとサイト別原稿 | 原稿は1つ（`title/foreword/body/afterword`）。投稿先 `site` で記法・機能を切替え、コピー時に変換 | `drafts.narou / drafts.alpha` に分離。既存原稿は**移行時点の投稿先側**へ入れる |
| メイン投稿サイト | `project.site`（`narou` / `alpha`）が事実上のメイン | フィールド名は変えず、意味を「メイン投稿サイト」とする。未設定は `narou` |
| 外部ID | エピソード ID のみ（UUID）。インポート元の外部 ID はなし | インポート時に `importKey`（外部ID・本文ハッシュ）を保持 |
| アルファのルビ | 公式ヘルプ（Qiita 引用）で `#漢字__かんじ__#`、別資料で `\|漢字《かんじ》` も可・傍点 `《《》》` | 変換先は `#__#`。双方向変換を純粋関数化しテスト |
| 画像タグ | なろう `<iコード\|ユーザID>`（公式ヘルプで確認）。アルファ `#__i_xxxxxxxx__#`（仕様書の例） | 目印 `【ここに画像を挿入：識別子】` に変換 |
| なろう／アルファの TXT 形式 | **実ファイル未入手** | 区切り条件で汎用的に解析し、サンプル入手後にプリセットを調整 |
| Google 権限 | `drive.file`。保存先は自動作成の「小説エディター」フォルダ（appProperties で識別）。Picker 未使用 | 保存先フォルダ選択を追加（Picker は API キーがある場合のみ。ない場合はフォルダ名を指定して作成） |
| 表示設定の保存先 | localStorage（端末単位） | 表示・ボタン設定は端末単位、メイン投稿サイト・章・原稿は作品単位 |
