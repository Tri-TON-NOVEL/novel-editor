## 7. データの復旧手順
1. **直前の操作を戻す**：入力は「↶ 戻す」。エピソードは「版」から、作品全体は「設定 → バックアップ → この作品のバックアップ版」から戻す。
2. **コピー・インポートを取り消す**：「○○用へのコピー前」「インポート前（自動）」の版から戻す。
3. **v3 移行前に戻す**：「設定 → バックアップ → v3 移行前のデータを書き出す…」で書き出したファイルを、改修前の版（スナップショット `00_改修前_2026.10.19-12.zip`）の「バックアップから復元」で読み込む。
4. **ブラウザのデータが消えた**：全体バックアップ、または自動バックアップのフォルダのファイルを「バックアップから復元」。
5. **プログラムを前の版に戻す**：`I:\Programs\NovelEditor_snapshots\` の ZIP を展開して GitHub に上げ直す。

## 8. 外部仕様への依存・既知の制約・未解決
- **なろう・アルファポリスの TXT の実ファイル形式**：未入手。サンプルをもらってプリセット（区切り・前書き後書きの判定）を調整する。フリーメモに当たる部分の自動抽出は未対応。
- **アルファポリスの記法**：ルビ `#漢字__かんじ__#` は公式ヘルプ（引用記事）で確認。画像タグ `#__i_xxxxxxxx__#` は仕様書の例に基づく。前書き・後書き欄の有無は未確認（アルファ側には欄を出していない）。
- **Google ドライブ**：保存先フォルダ・同名ファイルの照合・Picker は実機未検証。Picker には API キーが必要。
- 新しい形式（v3）の .json は、古い版のエディターでは開けない。
- 同じ作品を複数のタブで同時に編集すると、後から保存した方が残る（警告は出す）。
- 正規表現の区切り条件は、入れ子の繰り返しを拒否し、1行400文字・全体3秒で打ち切る（極端な条件は止める）。
