# 小説エディター 使い方

[README に戻る](../README.md)

## 画面の構成
- **左（目次）**：投稿先（メイン投稿サイト）、小説タイトル、あらすじ・全体プロット・設定・登場人物・活動報告、**章とエピソードの階層**。
  狭い画面では「☰ 目次」から開きます。
- **右（エピソード）**：「なろう用／アルファ用」の原稿タブ、版、エピソードタイトル、本文（前書き・後書き）、プロット、フリーメモ。

## 主な機能
### 章とエピソード
- 章は独立したデータで、エピソードは章に所属します（どこにも入っていないものは「未分類」）。
- 目次の「＋ 話」「＋ 章」、章の「⋯」（名前・プロット・上へ／下へ・削除）、章名を押して折りたたみ。
- エピソードの「⋯」（上へ／下へ・章を移動（プルダウン）・削除）。目次の並び順が「ファイル順」のときだけ出ます。
- 目次の上の検索欄で、開いている側の原稿のタイトル・前書き・本文・後書きと、プロット・フリーメモを探せます。見つかった話を押すとその場所を選択し、もう一度押すと次の場所へ移ります。
- 章を消しても、中のエピソードは未分類に移るだけです。
- 全体プロットの章と目次の章は同じものです（全体プロットで章タイトルと章プロットを編集）。
- 目次は「章あり／章なし」を選び、ファイル順／更新日時／作成日時／タイトル／本文の文字数／プロットの有無（昇順／降順）で並べ替えます。
  「章あり」は章ごとの中で並べ、「章なし」は章を抜きにして全エピソードを1つの一覧で並べます。

### なろう用・アルファ用の原稿（メイン／サブ）
- 左上の「投稿先」が**メイン投稿サイト**。原稿はなろう用・アルファ用を**別々に**持ちます（自動では同期しません）。
- エピソード画面の「なろう用／アルファ用」タブで編集する原稿を切り替えると、ルビ・傍点・挿絵・前書き・後書きの機能も切り替わります。
- **「メイン → サブにコピー…」**：変換後のプレビューと注意を見てからコピー。コピー先に内容があれば上書きの確認が出て、上書き前の状態は版に自動で残ります。

| | なろう | アルファポリス |
|---|---|---|
| ルビ | `\|漢字《かんじ》`（10文字まで） | `#漢字__かんじ__#` |
| 傍点 | `\|傍点《・・》` | `#傍点__・・__#`（`《《傍点》》` も読み込める） |
| 画像 | みてみんの URL を貼ると `<i1285249\|50921>` | `#__i_xxxxxxxx__#` |
| 変換するとき | なろう → アルファでは、挿絵タグがみてみんの URL（`https://50921.mitemin.net/i1285249/`）になります。アルファ → なろうでは、みてみんの URL は挿絵タグに戻り、アルファの画像タグは `【ここに画像を挿入：識別子】` の目印になります。変換できない書き方は原文のまま注意を出します |

### 入力欄
- 本文・プロット・**フリーメモ**（両サイト共通のメモ）・前書き・後書き。各欄に「コピー」と「⤢ 最大化」（Esc／戻る操作／右上のボタンで元に戻す）。本文・プロット・フリーメモには「↑」「↓」もあり、欄の一番上・一番下へ移れます。
- 「設定」→「表示」：**「簡易」「詳細」の2つの表示**を登録しておき、一番上の「使う表示」（簡易／詳細）で切り替えます。下の「簡易」「詳細」のタブで、それぞれの中身を決めます（今使っていない方を編集したときは、切り替えると反映されます）。それぞれの表示で決められるもの：
  - 本文の書体・文字サイズ
  - **エディター**：上のバーの「新しい作品」「ファイル」「リンク」の表示／非表示（「作品一覧」「設定」「戻す」「やり直す」「保存」はいつも表示）
  - **小説全体**：目次の「あらすじ」「全体プロット」「設定」「登場人物」「活動報告」「投稿サイトとの対応」の表示／非表示
  - **章・エピソード**：「全項目」（章・並べ替え・検索・一覧。今まで通り）か「リスト」（エピソードを選ぶプルダウンだけ。選んだエピソードを編集）
  - 入力欄（前書き・後書き・プロット・フリーメモ）、**文字数ラベル**、コピーボタン、最大化ボタン、本文最大化中の入力補助ボタンの表示／非表示
  - 最初は、「詳細」が今までの表示、「簡易」がボタンを減らした表示（章・エピソードは「リスト」）です。
- iPhone では「設定」→「表示」で、最大化したときの入力欄の高さ（自動／画面の縦の半分／ピクセル指定）を決められます。キーボードの上の部分に入力欄が隠れるときに使います。
- ルビ・傍点・記号・字下げ・一括置換、戻す／やり直す（上のバーの「設定」と「保存」の間）、本文とプロットの境目のドラッグ。
- 左の目次（投稿先〜章・エピソード）とエディターの境目もドラッグで幅を変えられます（ダブルクリックで元の幅。端末ごとに記憶）。
- **画像の一覧**：本文の上の「画像」に、本文にある画像（なろうの挿絵タグ・みてみんの URL・アルファの画像タグ）の数が出ます。
  押すと一覧になり、各みてみんURL自体をリンクとして開けます。「みてみんで開く」「本文のこの位置へ」「URL をコピー」もできます。

### TXT の一括インポート（「設定」→「インポート（なろう・アルファ）」）
1. 取り込む原稿（なろう用／アルファ用）・取り込み先（新しい作品／既存の作品）・TXT・文字コード（自動／UTF-8／Shift_JIS）
2. 区切りの条件（話・章・前書き後書き。行頭／行内、完全一致／前方一致／正規表現）で自動検出 → 行ごとに手で修正
   - **見出し（【…】など）の扱い**：見出しごとに「この行だけ消す／この行から塊ごと消す／前書き・後書きにする／残す」を選べます。
     既定の「なろう：ダウンロード TXT」では、区切り線（`--- エピソード2開始 ---`）と `【エピソードタイトル】` `【本文】` などの行は取り込まず、
     `【リアクション】` と作品情報（`【ユーザ情報】` `【Nコード】` `【種別】` `【完結設定】` `【年齢制限】` `【ジャンル】` `【作品に含まれる要素】` `【キーワード】`）の塊も取り込みません。
     最終話の後ろに付く株式会社ヒナプロジェクトの免責文、ダウンロード機能の説明、作成日時も既定で取り込みません。
     `【第１章】` は章の区切りで、次の行が章の小タイトル。`【エピソードタイトル】` は次の行が話のタイトルです（区切り線の前後どちらに章の見出しがあっても分けられます）。
   - 見出しの欄を書き換えたら「この条件で自動検出」で全文に反映します（入力中は重くならないよう反映しません）。
   - 「この条件を既定にする」で、次から最初に使う条件を決められます。
   - 「設定」→「投稿サイト」にユーザID・ユーザ名・作者名・Nコードを登録しておくと、TXT の `【ユーザ情報】` `【Nコード】` と違うときに、取り込む前に確認が出ます。
3. プレビュー（章・話・文字数・前書き後書き・画像・注意・既存との重複）→ 上書き／追加／スキップ／取り込み先を指定 → 取り込む

確定するまで作品は変わりません。既存の作品に取り込むときは「インポート前（自動）」のバックアップ版が残ります。途中の作業は残り、次に開くと再開できます。

### 保存とバックアップ
- **自動保存**（ブラウザ内）。状態は上に「保存中…／保存済み／⚠ 保存に失敗しました」。別のタブで同じ作品を編集していると警告します。
- **エピソードの版**：編集している内容は、いつもどれか1つの版です。一覧には「第○版　時刻　文字数」が並び、今編集している版が選ばれています（書くと、その版の時刻・文字数が新しくなります）。
  - **一覧で別の版を選ぶ**：今の版に今の内容をしまってから、選んだ版の内容に切り替えます（何も消えません。新しい版も作りません）。
  - **＋ 版を上げる**：今の版はそのまま残し、同じ内容で次の番号の版を作って、それを編集します（第1版から上げると第2版。番号は一番大きい版の次）。
  - **この版を削除**：今表示している版を、確認のうえ削除します。削除すると、残っている一番新しい版を表示します。版が1つしかないときは削除できません。
  - エピソードのファイルを開く・テキストを読み込む・メイン → サブにコピーで上書きするときは、自動で版を上げます（上書き前の内容は前の番号の版に残ります）。
- **作品全体のバックアップ版**（10分ごと・画面を閉じるときにも自動。設定 → 自動バックアップ）。

### 「保存」ボタン（上の一番右、「設定」の右）
- 今の内容を、全端末で共有する**自動バックアップ**に保存します（Ctrl+S／⌘S も同じ）。毎回、新しいバックアップが1つ増えます（古いものは「残す件数」で消えます）。
- まだ保存していない変更があると「保存●」になります。上の状態の表示には「保存 13:40」のように最後の時刻が出ます。
- 保存の前に、他の端末で新しい記録が保存されていないかを確かめ、あればどちらを使うか聞きます。
- 自動バックアップの保存先が決まっていないときは、「設定」→「自動バックアップ」を開きます。クラウド（Google ドライブ・OneDrive）のログインが切れているときは、ログインしてから保存します。
- 書いた内容そのものは、これとは別に、端末の中へ自動で保存されています（上の「端末に保存済み」）。

### 「ファイル」メニュー（手動）
- 明示的に、好きな場所・名前で保存する／開くときに使います。
- **全体（すべての作品・ひな型・設定を1ファイルに）**：開く／名前を付けて保存。開くと「まとめる／入れ替える」を選んで戻せます。
- **エピソード（今開いているもの）**：エピソード専用ファイル（なろう用・アルファ用の両方の原稿、プロット、フリーメモ）を開く（今のエピソードに上書き。上書き前は版に残る）／名前を付けて保存。
- **インポート（プレーンテキスト）**：今のエピソードの本文へ（UTF-8・Shift_JIS）。
- **エクスポート（プレーンテキスト）**：このエピソード・全エピソード（開いている側の原稿）。
- 以前の版で保存した「作品1つ」の .json は、全体の「開く」で作品として取り込めます。
- なろう・アルファから出力した TXT の一括インポートは「設定」→「インポート（なろう・アルファ）」です。
- **保存先**：「ファイル」のすべての保存・開くで、クラウドを設定した端末では「どこに保存／どこから開きますか？」（クラウド／この端末・その他）を選びます。「設定」→「ファイル」で「両方を使う／クラウドだけ／この端末・その他だけ」を選べます。「だけ」にすると選ぶ画面は出さず、すぐにそれぞれの画面を開きます。
  - **使うクラウド**は「設定」→「クラウド」で、**Google ドライブ**か **OneDrive** を選びます（端末ごと。切り替えると画面を読み直します。それぞれのログイン・フォルダの設定は別々に残ります）。準備の手順は README にあります。
  - クラウド：エディター独自の画面。フォルダをたどって選び、その場で「＋ 新しいフォルダ」も作れます（iPhone・iPad でも）。保存では、ファイル名を入れて「このフォルダに保存」、一覧のファイルを押すと上書き。同じ名前のファイルがあるときは、上書きせずに名前の後ろに「 (2)」などを付けます。前回使ったフォルダから始まります。
  - この端末・その他：PC の Chrome / Edge は保存先を選ぶ画面、**iPhone・iPad は共有メニュー（「"ファイル"に保存」で iCloud Drive などを選ぶ）**、それ以外はダウンロード。

### 自動バックアップ（「設定」→「自動バックアップ」）
- 役割は2つ：いざというときに戻すバックアップと、端末どうし（Windows・Mac・iPhone・iPad・Android）の**楽観的な同期**。
- 保存先（端末ごと）：**フォルダ**（PC の Chrome・Edge、Android の Chrome。PC のネットワークドライブ（NAS など）や、OneDrive・iCloud Drive・Google ドライブの同期フォルダも可）／**クラウド**（「設定」→「クラウド」で選んだ Google ドライブか OneDrive。iPhone・iPad はこちら）。
- 端末の中（ブラウザ）には、ここで設定しなくても、いつも自動で保存しています（書いた内容と「作品のバックアップ版」）。自動バックアップは、端末の外への保存です。
- **バックアップ先のフォルダは自分で作って選びます**（名前は自由）。「フォルダを選ぶ・作る…」の画面で新しく作ることもできます。選んだフォルダに直接保存し、エディターが勝手にフォルダを作ることはありません。選ぶまでは保存しません。
  - 端末どうしで同期するときは、すべての端末で**同じクラウド・同じフォルダ**を選んでください（PC の「フォルダ」方式なら、パソコン版 Google ドライブ・OneDrive の中の、そのフォルダ）。
  - iPhone・iPad と同期するときは、「クラウド」方式（Google ドライブか OneDrive）か、PC ならパソコン版のアプリの同期フォルダを使ってください（Web アプリは iPhone・iPad から iCloud に自動で書き込めないため）。
- ファイル名は「プレフィックス＋日時」（例：`iPad_20261022T001500Z.json`）。プレフィックスの既定は `Win_`・`Mac_`・`iPhone_`・`iPad_`・`android_` で、自由に変えられます。
- 変更があるときだけ、保存間隔ごと（設定可）と、画面を閉じる・別のアプリに切り替えるときに保存します。残す件数を超えると、この端末が保存した古いものから消えます。端末には最後に同期したバックアップの名前と時刻を記録します。
- **他の端末で新しいバックアップがあるとき**（起動したとき・「保存」を押したとき・保存しようとしたとき）は、どの OS・保存先でも同じ1つの画面が出ます。
  - 上に「他の端末（iPad_ 15:33）で新しいバックアップがあります」のお知らせ、下にバックアップの一覧（全端末の分。新しい順で、先頭が「最新」）。
  - 一覧から読み込むものを選びます（最新が候補ですが、どれでも選べます）。端末（プレフィックス）ごとに絞り込めます。
  - この端末にも保存していない変更があるときは「この端末の記録を使う（すぐ保存）」「あとで」、ないときは「読み込まない」も選べます。
  - 両方の端末を開いたまま書いていても、保存する前に他の端末の新しいバックアップに気づいたら、上書きせずにこの画面を出します。
- 「他の端末の更新を確認…」でも、同じ一覧の画面を開けます。
- 「読み込む」（または「ファイルから選ぶ」）を押すと、バックアップの中の小説を選んで（今開いている小説と同じものが最初に選ばれています）、次の3つから選びます。どの OS・端末でも同じです。
  - **上書き**：いま開いている小説を、選んだ小説の内容（タイトルから全部）で置き換えます。置き換える前の内容は「作品のバックアップ版」に残します。
  - **新小説**：選んだ小説を、新しい小説として追加して開きます（いま開いている小説はそのまま）。
  - **キャンセル**：何もせず、一覧に戻ります。
  - 小説の一覧の最後には **「⚙ 環境（設定・ひな型・リンク・アカウントなど）」** があります。これを選んでボタンを押すと、小説ではなく環境を読み込みます。入っているものが表示され、次の2つから選びます。読み込むと画面を読み直します。
    - **まとめる**：この端末の設定を残したまま足します（ひな型・リンク・TXT インポートの条件は足し合わせ、アカウントは空の欄だけ埋め、ほかはこの端末にない設定だけ入れます）。
    - **置き換える**：バックアップの設定で上書きします。表示・ファイルの保存先の選び方・自動バックアップの間隔と件数・目次の幅・iPhone の高さも、バックアップのものにします。
    - どちらでも、自動バックアップの保存先・プレフィックス・使うクラウドとそのログインは変わりません。
- 「バックアップから戻す」の「まとめる／入れ替える」のあとは、「新しい小説として追加」「中身を置き換え」の作品名を一覧で知らせ、変わった小説を開きます。
- **バックアップ・全体ファイルに入るもの**：すべての作品（本文・プロット・メモ・章、設定と登場人物の表、所属・同一人物のつながり、投稿サイトとの対応（Nコード・作品ID・作品URL）、活動報告）、作品の版、ひな型・リンク・投稿サイトのアカウント・TXT インポートの条件・「テキストに書き出す」の選び方などの設定（＝アプリの**環境**）。表示・ファイルの保存先の選び方・自動バックアップの間隔と件数・目次の幅・iPhone の高さも、「環境」を読み込むときのために入ります。自動バックアップの保存先・プレフィックス・ログインなど、端末そのものの記録は入りません。
- 他の端末のバックアップを読み込んだときは、設定も次のようにまとめます（この端末の設定は消しません）：ひな型・TXT インポートの条件・リンクは足し合わせ、アカウントは空の欄だけ埋め、それ以外はこの端末にまだない設定だけ入れます。
- 一覧に出るのは、バックアップ先のフォルダの中のバックアップです。それ以外の場所のファイルは「ファイルから選ぶ…」で選べます。
- 「バックアップから戻す」で、保存先のバックアップ（全端末の分）から選んで戻せます。
- ログインが切れると、上に「⚠ （クラウド名）にログイン」が出るので押してください。Google ドライブは約1時間で切れます。OneDrive は約1日続き（1時間ごとの更新は自動）、ログインは Microsoft のページに移動して行い、終わるとエディターに戻ります。

- 削除などの確認画面はエディター独自のもので、どの OS でも左が「キャンセル」、右が「OK／削除する」です。

### 設定
- 設定はすべて、変えた時点で反映・保存されます。設定画面の下は「閉じる」だけです（クライアントIDなどの文字の欄は、入れ終わって欄を離れたときに反映されます）。

### 投稿サイトとの対応（作品ごと）
- 目次の「小説タイトル」の下の「投稿サイトとの対応」に、なろうの Nコード・作品URL、アルファポリスの作品ID・作品URLを入れます。作品ごとに別々に持ち、入れなくても使えます。
- Nコード（作品ID）と作品URLは、片方を入れるともう片方が自動で入ります（アルファの作品URLを作るには、設定 → 投稿サイトのユーザIDが必要です）。
- 同じ Nコード・作品IDが別の作品にも入っていると知らせます。作品一覧にも表示されます。
- TXT インポートでは、取り込み先の Nコードと照合し、TXT の Nコードが別の作品に対応付けられていれば知らせます。

### 設定・登場人物の表
- **検索**：表の上の検索欄。「全項目」か列を選んで探せます。「分類」で絞り込みもできます。ひらがな・カタカナ、全角・半角の違いは無視し、空白で区切ると「すべてを含む」行を探します。当たった欄は色が付きます。
- **所属**（登場人物）：「＋ 所属」で「設定」の項目（国・種族・組織など）をいくつでも選べます（例：「魔族」と「ガルド王国」）。所属を押すと、そこでの立場・役職（「団長」など）を書けます。「（「設定」に新しく追加…）」で、その場で設定の項目も作れます。「設定」側の「所属する人物」に、所属している人物が自動で出ます。
- **同一人物**（登場人物）：名前を変えた同じ人物は、それぞれ別の行で書き、「＋ 同一人物」でつなげます。3人以上もつなげられます。名前を押すとその行へ移動し、「×」でつながりを外します。検索のとき「同一人物も表示」にしておくと、つながった人物も一緒に出ます。
- **非公開の書き方**：欄の中で、先頭に「＃」（半角の # も可）を付けた行は非公開の扱いです。名前の欄を「＃…」にすると、その行全体が公開用では出ません。
- **テキストに書き出す**：書き出す列と行（人物・項目）を選び、形式（見出し形式／1人1行／表）を選んでコピー、またはファイルに保存します。「公開用」にすると「＃」の行を除くので、話の途中で「これまでの登場人物」として載せるときに使えます。選んだ列と書式は次回も使われます。

### その他
- **活動報告のリンク**：「設定」→「リンク」の一覧に、「活動報告用」の **X** と **なろう活動報告** が入っています（削除はできません。名前・URL・並び順は変えられます）。ほかのリンクと同じく「リンク」メニューにも出ます。
  - 活動報告の画面の「X を開く」「なろう活動報告を開く」ボタンと、「X（旧Twitter）」「なろう 活動報告」の見出し（↗）は、ここに入れた URL を別のウインドウで開くだけです。投稿文は「コピー」で貼り付けてください。
  - X の URL の初期値は `https://x.com/home`、なろう活動報告は空です（自分の活動報告のページの URL を入れてください）。全作品共通で、バックアップにも入ります。
- 活動報告（X・なろう活動報告とひな型）、あらすじ、設定・登場人物の分類つき表、リンク、作品の3段階確認つき削除。

## iPhone・iPad・Android で使うとき
- iPhone・iPad：Safari で開き、共有 →「ホーム画面に追加」。Android：Chrome のメニュー →「アプリをインストール」。
- ホーム画面から起動すると、ブラウザが保存データを自動で消しにくくなります。それでも、自動バックアップ（Google ドライブか OneDrive）を使うか、ときどき「ファイル」→ 全体の「名前を付けて保存」をしてください。
- iPhone・iPad の Safari とホーム画面のアプリは、作品データも設定も別々に持ちます（片方で設定しても、もう片方には入りません）。
- フォルダを選ぶ機能（自動バックアップの「フォルダ」）は PC の Chrome・Edge と Android の Chrome だけです。iPhone・iPad では「クラウド」（Google ドライブか OneDrive）を使います。
