# 小説エディター 使い方

[README に戻る](../README.md)

## 画面の構成
- **左（目次）**：投稿先（メイン投稿サイト）、小説タイトル、あらすじ・全体プロット・設定・登場人物・活動報告、**章とエピソードの階層**。
  狭い画面では「☰ 目次」から開きます。
- **右（エピソード）**：「なろう用／アルファ用」の原稿タブ、版、エピソードタイトル、本文（前書き・後書き）、プロット、フリーメモ。

## 主な機能
### 章とエピソード
- 章は独立したデータで、エピソードは章に所属します（どこにも入っていないものは「未分類」）。
- 目次の「＋ 話」「＋ 章」、章の「⋯」（名前・プロット・上へ／下へ・削除）、章名を押して折りたたみ。
- エピソードの「⋯」（上へ／下へ・章を移動（プルダウン）・削除）。目次の並び順が「ファイル順」のときだけ出ます。
- 目次の上の検索欄で、開いている側の原稿のタイトル・前書き・本文・後書きと、プロット・フリーメモを探せます。見つかった話を押すとその場所を選択し、もう一度押すと次の場所へ移ります。
- 章を消しても、中のエピソードは未分類に移るだけです。
- 全体プロットの章と目次の章は同じものです（全体プロットで章タイトルと章プロットを編集）。
- 目次は「章あり／章なし」を選び、ファイル順／更新日時／作成日時／タイトル／本文の文字数／プロットの有無（昇順／降順）で並べ替えます。
  「章あり」は章ごとの中で並べ、「章なし」は章を抜きにして全エピソードを1つの一覧で並べます。

### なろう用・アルファ用の原稿（メイン／サブ）
- 左上の「投稿先」が**メイン投稿サイト**。原稿はなろう用・アルファ用を**別々に**持ちます（自動では同期しません）。
- エピソード画面の「なろう用／アルファ用」タブで編集する原稿を切り替えると、ルビ・傍点・挿絵・前書き・後書きの機能も切り替わります。
- **「メイン → サブにコピー…」**：変換後のプレビューと注意を見てからコピー。コピー先に内容があれば上書きの確認が出て、上書き前の状態は版に自動で残ります。

| | なろう | アルファポリス |
|---|---|---|
| ルビ | `\|漢字《かんじ》`（10文字まで） | `#漢字__かんじ__#` |
| 傍点 | `\|傍点《・・》` | `#傍点__・・__#`（`《《傍点》》` も読み込める） |
| 画像 | みてみんの URL を貼ると `<i1285249\|50921>` | `#__i_xxxxxxxx__#` |
| 変換するとき | なろう → アルファでは、挿絵タグがみてみんの URL（`https://50921.mitemin.net/i1285249/`）になります。アルファ → なろうでは、みてみんの URL は挿絵タグに戻り、アルファの画像タグは `【ここに画像を挿入：識別子】` の目印になります。変換できない書き方は原文のまま注意を出します |

### 入力欄
- 本文・プロット・**フリーメモ**（両サイト共通のメモ）・前書き・後書き。各欄に「コピー」と「⤢ 最大化」（Esc／戻る操作／右上のボタンで元に戻す）。
- 「設定」→「表示」：書体・文字サイズ、前書き・後書き・プロット・フリーメモの表示／非表示、コピーボタン・最大化ボタン、および本文最大化中の入力補助ボタンの表示／非表示（端末ごと）。
- iPhone では「設定」→「表示」で、最大化したときの入力欄の高さ（自動／画面の縦の半分／ピクセル指定）を決められます。キーボードの上の部分に入力欄が隠れるときに使います。
- ルビ・傍点・記号・字下げ・一括置換、戻す／やり直す、本文とプロットの境目のドラッグ。
- 左の目次（投稿先〜章・エピソード）とエディターの境目もドラッグで幅を変えられます（ダブルクリックで元の幅。端末ごとに記憶）。
- **画像の一覧**：本文の上の「画像」に、本文にある画像（なろうの挿絵タグ・みてみんの URL・アルファの画像タグ）の数が出ます。
  押すと一覧になり、各みてみんURL自体をリンクとして開けます。「みてみんで開く」「本文のこの位置へ」「URL をコピー」もできます。

### TXT の一括インポート（「設定」→「インポート（なろう・アルファ）」）
1. 取り込む原稿（なろう用／アルファ用）・取り込み先（新しい作品／既存の作品）・TXT・文字コード（自動／UTF-8／Shift_JIS）
2. 区切りの条件（話・章・前書き後書き。行頭／行内、完全一致／前方一致／正規表現）で自動検出 → 行ごとに手で修正
   - **見出し（【…】など）の扱い**：見出しごとに「この行だけ消す／この行から塊ごと消す／前書き・後書きにする／残す」を選べます。
     既定の「なろう：ダウンロード TXT」では、区切り線（`--- エピソード2開始 ---`）と `【エピソードタイトル】` `【本文】` などの行は取り込まず、
     `【リアクション】` と作品情報（`【ユーザ情報】` `【Nコード】` `【種別】` `【完結設定】` `【年齢制限】` `【ジャンル】` `【作品に含まれる要素】` `【キーワード】`）の塊も取り込みません。
     最終話の後ろに付く株式会社ヒナプロジェクトの免責文、ダウンロード機能の説明、作成日時も既定で取り込みません。
     `【第１章】` は章の区切りで、次の行が章の小タイトル。`【エピソードタイトル】` は次の行が話のタイトルです（区切り線の前後どちらに章の見出しがあっても分けられます）。
   - 見出しの欄を書き換えたら「この条件で自動検出」で全文に反映します（入力中は重くならないよう反映しません）。
   - 「この条件を既定にする」で、次から最初に使う条件を決められます。
   - 「設定」→「投稿サイト」にユーザID・ユーザ名・作者名・Nコードを登録しておくと、TXT の `【ユーザ情報】` `【Nコード】` と違うときに、取り込む前に確認が出ます。
3. プレビュー（章・話・文字数・前書き後書き・画像・注意・既存との重複）→ 上書き／追加／スキップ／取り込み先を指定 → 取り込む

確定するまで作品は変わりません。既存の作品に取り込むときは「インポート前（自動）」のバックアップ版が残ります。途中の作業は残り、次に開くと再開できます。

### 保存とバックアップ
- **自動保存**（ブラウザ内）。状態は上に「保存中…／保存済み／⚠ 保存に失敗しました」。別のタブで同じ作品を編集していると警告します。
- **エピソードの版**（版を上げる・戻す）と、**作品全体のバックアップ版**（10分ごと・画面を閉じるときにも自動。設定 → 自動バックアップ）。

### 「ファイル」メニュー（手動）
- **全体（すべての作品・ひな型・設定を1ファイルに）**：開く／**上書き保存**（Ctrl+S／⌘S。前回「全体」を保存・開いた場所へ）／名前を付けて保存。開くと「まとめる／入れ替える」を選んで戻せます。
- **エピソード（今開いているもの）**：エピソード専用ファイル（なろう用・アルファ用の両方の原稿、プロット、フリーメモ）を開く（今のエピソードに上書き。上書き前は版に残る）／名前を付けて保存。
- **インポート（プレーンテキスト）**：今のエピソードの本文へ（UTF-8・Shift_JIS）。
- **エクスポート（プレーンテキスト）**：このエピソード・全エピソード（開いている側の原稿）。
- 以前の版で保存した「作品1つ」の .json は、全体の「開く」で作品として取り込めます。
- なろう・アルファから出力した TXT の一括インポートは「設定」→「インポート（なろう・アルファ）」です。
- **保存先**：「ファイル」のすべての保存・開くで、Google ドライブを設定した端末では「どこに保存／どこから開きますか？」（Google ドライブ／この端末・その他）を選びます。「設定」→「ファイル」で「両方を使う／Google ドライブだけ／この端末・その他だけ」を選べます。「だけ」にすると選ぶ画面は出さず、すぐにそれぞれの画面を開きます。
  - Google ドライブ：エディター独自の画面。フォルダをたどって選び、その場で「＋ 新しいフォルダ」も作れます（iPhone・iPad でも）。保存では、ファイル名を入れて「このフォルダに保存」、一覧のファイルを押すと上書き。前回使ったフォルダから始まります。
  - この端末・その他：PC の Chrome / Edge は保存先を選ぶ画面、**iPhone・iPad は共有メニュー（「"ファイル"に保存」で iCloud Drive・OneDrive などを選ぶ）**、それ以外はダウンロード。

### 自動バックアップ（「設定」→「自動バックアップ」）
- 役割は2つ：いざというときに戻すバックアップと、端末どうし（Windows・Mac・iPhone・iPad・Android）の**楽観的な同期**。
- 保存先（端末ごと）：**フォルダ**（PC の Chrome・Edge、Android の Chrome。OneDrive・iCloud Drive などの同期フォルダも可）／**Google ドライブ**（「設定」→「クラウド」の保存先フォルダの中の「自動バックアップ」フォルダ。iPhone・iPad はこちら）。
  iPhone・iPad と同期するときは、すべての端末で「Google ドライブ」を選んでください（Web アプリは iPhone・iPad から iCloud・OneDrive に自動で書き込めないため）。
- ファイル名は「プレフィックス＋日時」（例：`iPad_20261022T001500Z.json`）。プレフィックスの既定は `Win_`・`Mac_`・`iPhone_`・`iPad_`・`android_` で、自由に変えられます。
- 変更があるときだけ、保存間隔ごと（設定可）と、画面を閉じる・別のアプリに切り替えるときに保存します。残す件数を超えると、この端末が保存した古いものから消えます。端末には最後に同期したバックアップの名前と時刻を記録します。
- **起動したとき**は保存先を調べます。
  - いちばん新しいのが自分の記録と同じ → そのまま。
  - 他の端末のほうが新しい（この端末は前回から変更なし）→「読み込む／読み込まない」を確認。
  - 他の端末のほうが新しく、この端末にも未バックアップの変更がある → ⚠「他の端末の記録を使う／この端末の記録を使う／あとで」を確認。
  - 読み込むときは**作品ごとに新しいほう**を使い、両方で書き換えた作品だけ、どちらを使うか聞きます。読み込む前の状態は「同期の前の状態を書き出す」で取り出せます。
  - 両方の端末を開いたまま書いていても、保存する前に他の端末の新しいバックアップに気づいたら、上書きせずに確認します。
- Google ドライブの画面などで自分で作ったフォルダは、同じ名前でもエディターからは見えません。既にあるフォルダを使うときは、PC で「設定」→「クラウド」の「既にあるフォルダを Picker で選ぶ」を一度使ってください（以後はどの端末のフォルダ選択画面にも出ます）。
- 「バックアップから戻す」で、保存先のバックアップ（全端末の分）から選んで戻せます。
- Google ドライブのログインは約1時間で切れます。切れると上に「⚠ Google ドライブにログイン」が出るので押してください。

- 削除などの確認画面はエディター独自のもので、どの OS でも左が「キャンセル」、右が「OK／削除する」です。

### 設定
- 設定はすべて、変えた時点で反映・保存されます。設定画面の下は「閉じる」だけです（クライアントIDなどの文字の欄は、入れ終わって欄を離れたときに反映されます）。

### その他
- 活動報告（X・なろう活動報告とひな型）、あらすじ、設定・登場人物の分類つき表、リンク、作品の3段階確認つき削除。

## iPhone・iPad・Android で使うとき
- iPhone・iPad：Safari で開き、共有 →「ホーム画面に追加」。Android：Chrome のメニュー →「アプリをインストール」。
- ホーム画面から起動すると、ブラウザが保存データを自動で消しにくくなります。それでも、自動バックアップ（Google ドライブ）を使うか、ときどき「ファイル」→ 全体の「名前を付けて保存」をしてください。
- iPhone・iPad の Safari とホーム画面のアプリは、作品データも設定も別々に持ちます（片方で設定しても、もう片方には入りません）。
- フォルダを選ぶ機能（自動バックアップの「フォルダ」）は PC の Chrome・Edge と Android の Chrome だけです。iPhone・iPad では「Google ドライブ」を使います。
