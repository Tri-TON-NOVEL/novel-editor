# サイトごとの目次順（仕様）

2026-11-19　あや綴り 0.97 で実装済み（作りながら決めたことは末尾の「実装で決めたこと」）

## 目的

カクヨムで第3話と第4話を入れ替えたときのように、投稿サイトごとに話の並びが違ってもよいようにする。

## 決まったこと

| 項目 | 決定 |
|---|---|
| サイトごとに持つもの | 話の並びだけ。章（部・章）の構成は3サイト共通 |
| 目次の表示 | 並び順で選ぶ（「目次順（なろう）」「目次順（カクヨム）」「目次順（アルファ）」。使うサイトだけ） |
| 並びの違いの入れ方 | 取り込み（ZIP・TXT）で自動、さらに手で ↑↓ |
| 新しい話の位置 | 各サイトで、すぐ前の話のあと |

## データ

- `project.episodes` の並び＝**メイン投稿先の目次順**（今の「目次順」と同じもの）。
- 新しく `project.siteOrder` を持つ。中身は `{ kakuyomu: [話のID, …], alpha: […] }` の形で、メイン以外のサイトの並びを入れる。
  - メインと同じ並びのサイトは持たない（キーなし＝メインと同じ）。
  - 読み込むときに整える。
    - なくなった話の ID は外す。
    - 足りない話は「すぐ前の話のあと」へ入れる。
    - 章の順で並べ直す（章は共通なので、意味があるのは章の中の順番だけ）。
- メイン投稿先を変えたときは並びを入れ替える。
  - 前のメインの並びを `siteOrder` へ移す。
  - 新しいメインの並びを `project.episodes` にする。
- 互換性
  - 古い版で開いても、`project.episodes`（メインの並び）はそのまま使える。`siteOrder` は読み飛ばされるだけで、消えない。
  - 古い版で話を足したり消したりしても、新しい版で開いたときに上の「整える」で直る。
  - v3 のバックアップやファイルを読み込むときは、ほかの v4 の項目と同じ扱いにする。つまり、この端末の `siteOrder` を残す。
  - 保存形式のバージョンは上げない（項目を足すだけ）。

## 画面

### 目次（左）

- 並び順の選択肢を次のようにする（使うサイトだけ、メインを先に並べる）。
  - 目次順（なろう）／目次順（カクヨム）／目次順（アルファ）
  - タイトル／更新日時／作成日時／本文の文字数／プロットの有無
- 今までの「目次順」の設定（保存値 `file`）は、「目次順（メイン投稿先）」として読む。
- 目次順のときは、話の行の ↑↓ と「⋯」の上へ／下へで並べ替えられる。
  - 変わるのは、表示中のサイトの並びだけ。
  - 章の中だけで動く（章の順番は共通のまま）。
- 「ほかの章へ移す」と、章自体の並べ替えは3サイト共通（今までどおり）。

### 取り込み

既存の作品へ取り込むとき：
- 組み合わせた話を、ファイルの順（カクヨムなら目次の順、なろう・アルファなら TXT の順）に並べ、その結果をそのサイトの並びにする。
- そのサイトがメインなら `project.episodes` が並べ替わる。
- 並べ替えるのは章の中だけ。今ある話の章は変えない。
- ファイルにない話は、そのサイトの並びの中で今の前後関係を保つ。
- プレビューで、並びが変わる話の数を知らせる（例：「カクヨムの並びが 2話変わります」）。

新しい作品として取り込むとき：
- 今までどおり、ファイルの順が `project.episodes` になる。

### 書き出し

- 「エクスポート」→「全エピソード…」は、書き出すサイトの並びで出す。

## 変えないもの

- 伏線の「発生した話」の話数、串刺し検索、全体プロット：メインの並び（`project.episodes`）を使う。
- サイト間のコピー、稿、活動報告：並びに関係しない。

## 後でやること

- マニュアル
  - 「章とエピソード」に並び順の説明を足す。
  - 取り込みに、並びが変わることを書く。
- マニュアル画像：並び順の欄に「ファイル順」が写っているので撮り直す。
- 自動テスト
  - 整える処理
  - メインの切り替え
  - 取り込みでの並び
  - 古い版のデータの読み込み

## 対象外（今回はしない）

- サイトごとの章の構成（なろうは章だけ、カクヨムは部と章、など）。

## 実装で決めたこと

- メインの並びを変えたとき（↑↓・取り込み・メインの切り替え）も、ほかの使うサイトの並びはそのまま残す（記録のないサイトは、その時点の並びを記録する）。
- 取り込みで原稿が全部同じ（全部スキップ）でも、並びが変わるなら「取り込む」を押せる。確認の画面にも「カクヨムの並びが N話変わります」を出す。
- 取り込みの照合：本文が同じ話が複数あるときは、まだ組にしていない話を、タイトルが同じものから選ぶ（同じ本文の第3話・第4話が、どちらも第4話と組になっていた）。
- 目次の並び順の欄を広げるため、昇順／降順のボタンは矢印（↑／↓）だけにした（説明はボタンにカーソルを当てると出る）。
- ほかの章へ移した話は、どのサイトの並びでも、移した先の章の「メインですぐ前にある話のあと」に入る。
