# サイトごとの目次順（取りやめ）

2026-11-19　あや綴り 0.97

一度作ったが、取りやめた。目次順は今までどおり3サイト共通。

## 取りやめた理由

- 同じ ↑↓ でも、どのサイトの並びを見ているかで結果が変わり、ややこしい。
- 並びがずれていても、目次を見ただけでは気づけない。
- 実際には、どのサイトも同じ順番で投稿することがほとんど。

## 代わりにしたこと

- 既存の作品へ取り込むとき、ファイルの話の順番が今の目次順と違えば、プレビューに「目次順を ZIP（TXT）の順に並べ替える（N話）」を出す。最初は選ばれていない。
  - 選ぶと、章の中の順番をファイルに合わせる（3サイト共通の目次順が変わる）。ファイルにない話は今の位置のまま。
  - 原稿が全部同じ（全部スキップ）でも、並べ替えを選べば取り込める。
- 取り込みの照合：本文が同じ話が複数あるときは、まだ組にしていない話を、タイトルが同じものから選ぶ（同じ本文の第3話・第4話が、どちらも第4話と組になっていた）。
