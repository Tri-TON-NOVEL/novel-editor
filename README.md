# Tri-TON Video Studio v4.0 — ローカル版

## v4.0 の機能

- 再生中は「Ⅱ 一時停止」と「■ 停止」。一時停止は現在位置を維持し、停止は先頭へ戻します。
- 素材Explorerに動画のサムネイル（代表フレーム）と画像サムネイルを表示。チェックで一括非表示にできます。
- 動画のコマ画像をsRGB PNGで生成し、クリップの暗色乗算を廃止。レイヤーの非表示／ミュートは行全体を暗くします。
- タイムラインの「行の高さ」をスライダーで24～100pxに調整できます。
- タイムスキップは5秒が初期値。1秒・5秒・10秒・30秒を選択、または数値を自由入力します。
- **保存** は編集中の階層構成・時間位置・素材ファイルの実体をブラウザのIndexedDBに保存し、同じURLでの次回起動時に復元します。**「構成を書き出す」** は素材を含まないJSONをダウンロードします。
- 素材Explorerの「● 収録」から複数カメラの選択、マイク入力選択、画面共有から動画・音声を取り込み、収録後にレイヤーへ追加できます。画面収録はディスプレイ／ウィンドウ／タブをブラウザの選択ダイアログで指定します。範囲指定時はプレビュー上で長方形を描き、そこを切り出して録画します。
- システム音とマイクの混合録音、カーソル有無はブラウザが対応した範囲で有効。特定ディスプレイをAPIから強制指定したり、複数ディスプレイ全体を一括録画することはブラウザの権限制約でできません。
- 添付の ScreenCaptureRecorder に合わせた **LKV v2 暗号化／復号** に対応しました。LKVを読み込むとパスワード入力後に動画を復号し、暗号化メタデータ内の表示名を素材名として使います。出力時にはパスワード確認・保存ファイル名の秘匿を選べます。方式はAES-256-GCM、PBKDF2-SHA256（60万回）、1MiBチャンク。LKV v1の読み込みにも対応しています。
- **高速書き出し** を追加しました。Chrome/EdgeなどWebCodecs VP8対応ブラウザでは、描画したフレームを独立したタイムスタンプで圧縮しWebMへ格納します。従来のMediaRecorder方式は選択可能な互換モードとして残しました。高速化は保証値ではなく、特に動画のフレームシークが多い場合は素材デコードが律速します。

**注意：** 保存データはURLのオリジンごとに独立します（localhostとLAN HTTPSは別）。ブラウザのサイトデータ削除・プライベートモード・ストレージ容量不足では失われる場合があります。大きな動画を保存する前に容量を確認してください。画面収録・カメラはPC上のChrome/Edgeで優先的にテストしてください。

**暗号化の範囲：** LKV出力ファイルは暗号化されますが、**編集中に復号した素材やブラウザの「保存」データは暗号化されません**。機密性が必要な場合はブラウザの保存を利用せず、OS側でもドライブ暗号化などで保護してください。`.lkvc` 形式のフォルダー目録の生成・読込・名前変更は今回は未実装です。動画のLKV形式自体はソースコードに合わせていますが、実機の Secure Video Player との相互運用テストは未実施です。

## v3.3 で変更した操作

- **オブジェクトの選択：** タイムライン上の色付きクリップをクリックします。黄色の枠がつき、右側のプロパティにそのオブジェクトの開始時刻・表示時間・位置・大きさ・固定回転角度・アニメーションが表示されます。
- **再生位置の移動：** クリップのクリックでは黄色い再生線は動きません。**上部の秒目盛りをクリック**したときだけ移動します（ほかに再生ボタン・移動秒数ボタン・下段の再生シークバーでも移動できます）。
- **クリップの時間移動：** 色付きクリップの内側をドラッグすると時間位置を変更できます。左右の端をドラッグするとトリムできます。
- **PowerPoint風の強調アニメーション：** 右側の「強調アニメーション」に回転と縦横振動を追加。開始秒・長さ・強さ・振動数を指定できます。既存の登場・退場・脈動・横揺れ・振り子も使用可能です。
- v3.2 のJSONプロジェクトも読込可能です。

以前の版との混同を避けるため、今回のフォルダーは `Tri-TON-Video-Studio-v4.0`、PCの起動URLは **`http://localhost:8819/`** です。

## 起動方法（Windows 11）

1. ZIP を任意のフォルダーに展開します。ZIP の中のファイルを直接開かないでください。
2. 同じ PC の Chrome / Edge で試す場合は **`start-local.bat`** をダブルクリックします。
3. PowerShell のウィンドウに表示された **`http://localhost:8819/`** を開きます。ウィンドウを閉じるとサーバーも終了します。

`start-local` は Python または PowerShell の簡易 HTTP サーバーを使用します。`localhost` はブラウザが安全な接続元として扱うため、PC 上での PWA テストに利用できます。

### 同じ Wi-Fi の iPhone / iPad でも使う場合

1. [Caddy 公式サイト](https://caddyserver.com/download)から Windows 用 `caddy.exe` をダウンロードし、この README と同じフォルダーに置きます。すでに Caddy が PATH にあるなら不要です。
2. **`allow-lan-firewall.bat`** を管理者として実行し、Windows ファイアウォールに *プライベートネットワーク・同一サブネット限定* の通信規則を追加します。
3. **`start-lan-https.bat`** を実行します。表示された `https://(PCのIP):8451/` を iPhone / iPad の Safari で開きます。
4. 証明書エラーを解消するには、同じ画面に表示される `http://(PCのIP):8794/root.crt` から **自分の Windows PC が発行したルート証明書だけ** をダウンロードし、iPhone / iPad でプロファイルをインストールして「証明書信頼設定」で完全な信頼を有効にします。
5. 通信を停止する際は Caddy を起動した PowerShell ウィンドウで Enter。不要になった通信規則は **`remove-lan-firewall.bat`**（管理者）で解除できます。

証明書の信頼はこの PC を管理している場合にだけ実施してください。ルーターのポート転送は不要で、設定しないでください。ウイルス対策ソフト独自の LAN ブロック機能がある場合は、Windows 側のファイアウォール許可だけではつながらないことがあります。

## v3 で操作できること

- 左上に独立レイヤーと子レイヤーの階層。親の開始時刻に対する相対時刻で子が動き、親の移動や拡縮に追従します。
- 動画、画像、音声、テキスト、図形を追加。レイヤーの順序は左上の階層リストの**同じ階層内でドラッグ**して入れ替えます。
- 「選択レイヤーの子に追加」を押すと、その次に追加する素材を子レイヤーにできます。
- 動画を選び、切り抜きモードで**四角・円・楕円・多角形・フリーハンド**をキャンバスに描くと、その形状を持つ動画の子クリップを生成します。多角形は頂点をクリックし「形状確定」を押します。
- キャンバスの「選択・移動」「拡大縮小」ボタンで操作を切り替えます。画面全体の表示倍率は右上の `−` / `＋` / `フィット`。
- 下部の細いタイムラインでクリップの移動、両端トリム、分割、再生位置移動。一定秒数の前後ジャンプ。
- プロジェクト構造を JSON 保存・読込。音声と動画と画像の素材実体は JSON に入りません。再読込時は同名の元ファイルを素材Explorerへ追加してください。
- 書き出しダイアログでファイル名を入力し、ブラウザが対応する動画形式に書き出します。

### 素材Explorerについて

ブラウザ上の Web アプリが Windows のドライブ全体や iPad の全ストレージを無断で一覧表示することはできません。左下の「＋ファイル」「フォルダ」を使って、**ユーザーが許可した範囲**の仮想フォルダー構造を表示します。iPad では「ファイル」アプリのファイル選択が使えますが、OSやSafariによってフォルダー一括選択の制約があります。

## 現時点の制限

- 動画書き出しは **映像のみ**。プレビューの音声レイヤーは再生できますが、書き出しファイルに音声を多重化する処理は未実装です。収録した動画には音声が入りますが、編集後の動画書き出しではまだ無音です。
- 大容量・長時間・高解像度の動画を扱う性能と書き出し品質は、端末とブラウザの動画デコーダー・エンコーダーに依存します。
- 書き出しはブラウザで利用可能な WebM / MP4 形式のみです。Safari を含む各ブラウザでは結果が異なるため、まず短い素材で試してください。
- レイヤーの切り抜きは、選択した動画領域を指定形状で抜き出す機能です。人物を自動認識して追跡する機能ではありません。
- 元素材は端末内で扱い、サーバーへアップロードしません。「保存」時にはブラウザ内のIndexedDBへコピーするためディスク空き容量が必要です。

## 構成

- `dist/`: ブラウザで表示するアプリ（HTML、CSS、JavaScript、PWA）
- `start-local.*`: この PC だけのテストサーバー
- `start-lan-https.*`: Caddy による LAN 内 HTTPS サーバー
- `allow-lan-firewall.*`、`remove-lan-firewall.*`: LAN 用ファイアウォール規則

サーバー用フォルダーは **`dist`** です。ソースは `dist/app.js`（UI・操作）と `dist/engine.js`（動画描画・階層モデル）に分離しています。


## v4.0 MP4高速書き出し
- 書き出しダイアログの初期選択は **MP4高速（WebCodecs H.264）** です。WebM高速（VP8）と従来方式も選択できます。
- WebCodecsでフレーム単位のH.264エンコードを行い、MP4コンテナ（ISO BMFF）へ格納します。リアルタイム録画の待機はありません。
- **音声は未出力** です。MP4エンコード支援がブラウザで提供されない場合にはWebM高速を選択してください。
- ハードウェア支援の有無、合成負荷で処理時間が変わります。速度は保証されません。
- Windows PCの接続先は http://localhost:8819/、LAN HTTPSは従来のCaddyが必要です。

## v4.0 PowerPoint取り込み

素材Explorerの「PowerPoint」から .pptx を選択。各ページをPNG画像化して、5秒ずつの子オブジェクトとして1つの親レイヤー内に配置します。各ページの時間・位置・アニメーションを個別に編集できます。変換はブラウザ内で行われます（アップロード不要）。

**制限:** PowerPoint本体の描画エンジンではありません。基本的な文字・単純図形・埋込PNG/JPEG画像のみ対応し、SmartArt、グラフ、表、マスター、特殊フォント、アニメーション、動画等は忠実に再現できません。凝ったスライドはPowerPointからPNGに書き出して取り込んでください。

## v4.0 UI と制限
- 「ファイル」メニュー: 「保存（構成JSON）」はレイヤー等の定義のみダウンロード。元の動画・画像・音声のバイト列は含みません。「作業状態を端末に保存」はIndexedDBに素材も含む復元データを保存します。容量制限があります。
- 「素材Explorer」のファイルメニューは一般ファイル・PowerPoint・フォルダを選択。「選択素材を追加」を押すまでタイムラインには載りません。「一覧から除去」はExplorerのリストから削除します（編集中レイヤーは保持）。
- タイムラインは「1時間」で1時間幅に縮小可能。＋／−で拡大縮小、横スクロールバーおよびShift+ホイール・トラックパッド横スクロールで移動。
- レイヤーの「⋯」から次回追加を子レイヤーにする操作、親から独立する操作を選択できます。
- 「音声分離」は試験的実装です。選択した動画と同一素材を参照する子音声レイヤーを作ります。音声を独立ファイルへ抽出しません。「音声を結合」はレイヤーの親子関係を変更する操作で、MP4への音声多重化ではありません。
- iPhone/iPadでは端末APIの制限があります。Windowsでの実機ブラウザテストは未完了です。

  - 非対応：Sorenson H.263・VP6・Screen Video など古い映像形式の FLV は、エラーメッセージを出して取り込みません。非対応の音声形式（Nellymoser・Speex など）は、音声を省いて映像だけ取り込みます。
  - 録画が途中で切れた FLV は、読める部分まで変換します。
  - 拡張子が .flv でも中身が別形式のファイル（昔のダウンロードツールでよくあります）は、中身を調べて扱います。MP4/F4V・WebM/MKV ならそのまま読み込み、AVI・WMV・MPEG などは中身の形式名を出して「MP4に変換してから」と案内します。動画の代わりにWebページ（ダウンロード失敗時の画面）が入ったファイルや空のファイルも、その旨を表示します。先頭に余分なデータが付いたFLVも読み込めます。
  - 変換中は元ファイルをメモリ上に読み込むため、ファイルサイズの約2倍のメモリを一時的に使います。
- タイムラインの黄色線が、目盛り側とレイヤー側でずれる問題を修正しました。再生・移動・入力のたびに目盛り側だけが拡大率とスクロール位置を無視して置かれていたこと、縦スクロールバーが出るとレイヤー側だけ幅が狭くなることが原因でした。レイヤー背景の縦線も目盛りの位置に揃えました。
- 黄色線（再生位置）が表示範囲の外に出ると、タイムラインが自動でスクロールして追いかけます。再生中はページをめくるように進み、移動ボタンや秒数入力で飛んだときは黄色線を中央に表示します。自分で横スクロールした後の編集操作では、表示位置は動きません。
- **切り抜き（クリップ）領域の表示**：編集中のキャンバスで、切り抜きの形をオレンジの点線で表示します。選んだ切り抜きは、親動画のどこから切り抜いたかも水色の点線で表示します。書き出した動画には入りません。
- **オブジェクト選択**（タイムライン上部のボタン）：オンにすると、レイヤー内の個々のオブジェクトを選べます。カットした区間はそれぞれ1つのオブジェクトで、カットしていないクリップは全体で1つです。クリックで選択（黄色の枠）、ドラッグで移動、Deleteキーまたは「削除」ボタンで、そのオブジェクトだけを削除します。
  - 親子の連動：親動画の区間を動かしたり消したりすると、連動している子（切り抜き・分離した音声）の表示も一緒に変わります。その区間の中に収まっている連動していない子（文字・画像など）は、一緒に移動・削除されます。
  - キーボードのDeleteでの削除も、Undoで元に戻せるようにしました。
- **親子関係を外したときの状態**：親動画に連動している子（切り抜き・分離した音声）を最上位へ移動したり、「親から独立」したり、「親動画のカット・区間移動に連動」のチェックを外したりした場合、元の動画に戻らないようにしました。親動画のカット・区間の移動・除去・再生速度をそのまま引き継いで切り離します。「親から独立」では、画面上の位置も保つようにしました。
- **動作が落ちる問題の対策**：
  - タイムラインの縮尺・目盛り・スクロールを変えるたびに、コマ画像用の隠れた動画デコーダーを毎回作り直していたのをやめ、使い回すようにしました（同時に最大3ファイル）。コマ画像の取得は、操作が止まってから行います。
  - 目盛りの単位が表示範囲よりずっと大きいとき（例：目盛り1時間で0.1秒表示）に、レイヤー背景の縦線用に巨大な画像を作っていたのを止めました。
- **ブックマーク**を、動画だけでなく音声・画像のレイヤーにも設定できるようにしました。
- **FLVの自動変換**：「＋ファイル」、フォルダ選択（Chrome/Edgeのフォルダ選択を含む）、Windowsのエクスプローラーからのドラッグ＆ドロップの、どの方法でも読み込み時に自動でMP4へ変換します。変換中は素材Explorerに進み具合を表示します。失敗した場合は、ファイル名と理由を表示します。
- **ファイルのドラッグ＆ドロップ**：Windowsのエクスプローラーから、動画・音声・画像・FLVをアプリの画面に直接ドロップして読み込めます。
- **設定の記憶**：次の設定を覚えておき、次回起動時に再現します（このブラウザ内に保存）。タイムラインの目盛り・表示目盛り数・行の高さ・コマ画像表示、素材のサムネイル表示、各区画の幅と高さ、キャンバスサイズと表示倍率、移動秒数、プレビュー再生速度、全ミュート、書き出し方式・ファイル名、収録のカメラ・マイクなどの選択、プロパティの表示タブ。編集中のプロジェクト自体は、これまでどおり「作業状態を端末に保存」「開く」で扱います。
- **再生速度**（0.1〜3倍）：再生ボタンの列の「⏩」ボタンで、プロパティ領域に速度設定を開きます。リストから選ぶか「カスタム…」で数値を入力します。
  - プレビュー再生速度：編集画面で確認するときの速度です。クリップや書き出しには影響しません。
  - 選択クリップの速度：動画・音声クリップの素材を何倍速で使うかです。書き出しにも反映されます。クリップの長さは変わりません。「配置・外観」タブの「クリップの速度」でも同じように設定できます。
  - これまで、プロパティで1倍未満の速度を指定できなかった不具合を直しました。
