# 小説エディター

小説家になろう・アルファポリス向けのシンプルな小説エディターです。
Windows・Mac・iPad のブラウザで動く Web アプリ（PWA）です。

## できること

- **作品（小説タイトル）ごとにエピソードを追加**していく構成です。左の目次でエピソードを切り替えます。
  - エピソードの追加・並べ替え（↑↓）・削除ができます。
  - 削除は目次の「削除」からもできます。間違って消さないよう、2回確認が出ます。
  - iPad の縦向きなど幅が狭いときは、「☰ 目次」から開きます。
- 小説タイトル、エピソードタイトル、本文、プロット、作品メモは、それぞれ **ボタン1つで別々にコピー** できます。
- 文字数の表示（全体／空白・改行を除いた数）
- **投稿先の切り替え（小説家になろう／アルファポリス）**：選んだ時点で、エディターの機能が切り替わります。

  | 機能 | なろうモード | アルファポリスモード |
  |---|---|---|
  | ルビ | `\|漢字《かんじ》`（10文字まで） | `#漢字__かんじ__#` |
  | 傍点 | `\|傍点《・・》` | `#傍点__・・__#` |
  | 挿絵 | みてみんの画像 → `<i1149234\|50921>` | なし（サイト上で画像をアップロード） |
  | 前書き・後書き | あり（後書きはひな型あり） | なし（内容は残り、非表示になるだけ） |
  | 記号・字下げ・一括置換 | あり | あり |

  - 「ルビ」「傍点」「記号」は、選択している文字に対して働きます（前書き・後書きの欄でも使えます）。
  - 本文のコピーや書き出しでは、投稿先の書き方に自動で変換されます。同じ原稿を両方のサイトに投稿できます。
  - 投稿先を切り替えたときに、原稿そのものを変換することもできます。
  - **字下げ**：段落の先頭に全角スペースを入れます。「 などで始まる行や、すでに字下げしてある行は除きます（なろうの自動字下げと同じ考え方）。
  - **一括置換**：このエピソードだけ、または全エピソードの文字列をまとめて置き換えます。
- **挿絵（なろうのみ）**：みてみんの画像ページURL（例：`https://50921.mitemin.net/i1149234/`）を本文に貼り付けると、
  なろうの挿絵タグ `<i1149234|50921>` に自動で変わります。「挿絵」ボタンからも入れられます。
  アルファポリスモードでは、URL は変換されずにそのまま貼り付けられます。
- **活動報告**：X の投稿文（全角140字のカウント付き、「X で開く」ボタンあり）と、なろうの活動報告（タイトル・本文）を書けます。
  - **ひな型** を登録しておくと、作品名・話数・エピソード名・URL を自動で差し込めます。
  - 差し込み文字：`{作品名}` `{話数}` `{エピソード名}` `{URL}` `{なろうURL}` `{アルファURL}` `{日付}`
  - URL は「作品メモ・設定」で作品URLを入れておくと使えます（なろうは作品URL＋話数）。
- **自動保存**：入力するたびに、端末のブラウザ内へ保存されます。
- **作品一覧**：端末に保存されている作品を切り替えたり削除したりできます。
- **ファイル保存・読み込み**（.json に作品全体をまとめて保存。.txt も読み込み可）
- エピソード単位、または全エピソードまとめての .txt 書き出し（投稿先の書き方に変換）
  - Windows・Mac の Chrome / Edge：同じファイルへ上書き保存できます。
  - Safari（Mac・iPad）：保存は「書き出し」になります。iPad では「ファイル」アプリに保存されます。
- 本文・プロットを .txt で書き出し
- **Google ドライブ** への保存・読み込み（「小説エディター」フォルダに保存されます）
- `Ctrl+S`（Mac は `⌘S`）：クラウドに連携済みならクラウドへ、そうでなければファイルへ保存します。
- オフラインで起動できます（ホーム画面に追加した場合）。

iCloud・OneDrive・Box などは、各サービスの同期フォルダ（iPad では「ファイル」アプリ）に
ファイル保存すれば、そのまま同期されます。

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリ（例：`novel-editor`）を作り、このフォルダの中身をアップロードします。
2. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存します。
3. 数分で `https://<ユーザー名>.github.io/novel-editor/` から使えるようになります。

公開されるのはエディターのプログラムだけです。原稿は各自の端末と Google ドライブにしか保存されません。

### iPad で使うとき
Safari で開き、共有ボタン →「ホーム画面に追加」を選んでください。
ホーム画面から起動すると、Safari が端末内の保存データを自動で消すことがなくなります。

## Google ドライブを使うための準備（最初に1回だけ）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作ります。
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効にします。
3. 「Google Auth Platform」（OAuth 同意画面）を設定します。
   - アプリ名とサポートメールを入力し、対象は「外部」を選びます。
   - 「データアクセス」で、スコープ `https://www.googleapis.com/auth/drive.file` を追加します。
   - 「対象」の **テストユーザー** に、自分の Gmail アドレスを追加します。
4. 「クライアント」→「クライアントを作成」で、種類に **ウェブ アプリケーション** を選びます。
   - 「承認済みの JavaScript 生成元」に次を追加します。
     - `https://<ユーザー名>.github.io`
     - `http://localhost:8765`（手元で試す場合）
5. 表示された **クライアントID** をエディターの「設定」に貼り付けます。
   - 各端末で入力したくない場合は、`js/providers/gdrive.js` の `DEFAULT_CLIENT_ID` に書いておくこともできます。クライアントIDは秘密情報ではないので、公開しても問題ありません。

補足：

- 「テスト中」の状態では、テストユーザーに登録した人しかログインできません。また、約7日ごとにログインし直しが必要です。
- 他の人にも使ってもらう場合は、「対象」で **本番環境に公開** してください。`drive.file` だけを使うアプリは、通常 Google の審査なしで公開できます。
- このアプリが Drive で触れるのは、このアプリで作ったファイルだけです。

## 手元で試す（Windows）

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

ブラウザで http://localhost:8765/ を開きます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `styles.css` | 画面 |
| `js/app.js` | 画面の動作・自動保存・コピーなど |
| `js/db.js` | 端末内保存（IndexedDB） |
| `js/format.js` | 作品（エピソード入り）のデータ形式・文字数カウント |
| `js/notation.js` | なろう／アルファポリスの記法変換、挿絵タグ、X の文字数、ひな型 |
| `js/localfile.js` | ローカルファイルの読み書き |
| `js/providers/` | クラウド保存先。OneDrive・Dropbox などはここに同じ形で追加します |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面アイコン |

アプリを更新したときは、`sw.js` の `VERSION` を上げてください（古いキャッシュが残らないようにするためです）。
