# 小説エディター

「小説家になろう」「アルファポリス」に投稿する小説を書くための、ブラウザで動く執筆エディターです。
Windows・Mac・iPhone・iPad・Android のブラウザで動き、ホーム画面に追加するとアプリ（PWA）として使えます。

- **バージョン**：4.9（`2026.10.22-4.9`）
- **使い方の詳細**：[docs/使い方.md](docs/使い方.md)
- **アプリ**：GitHub Pages で公開した URL（例：`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開くだけで使えます。

> 本アプリは無保証です。利用によって生じた損害について、作者は一切の責任を負いません。詳しくは下の[免責事項](#免責事項)をお読みください。

## 主な特徴

- **なろう用・アルファ用の原稿を別々に管理**：ルビ・傍点・挿絵の書き方の違いを変換しながら、メイン → サブへコピーできます。
- **章とエピソード**：章ごとの階層、並べ替え、章の移動、目次での全文検索ができます。
- **作品の資料**：あらすじ、全体プロット（章ごと）、設定・登場人物の表、活動報告とひな型をまとめて扱えます。
- **書くための機能**：ルビ・傍点・記号・字下げ・一括置換、入力欄の最大化、文字数、画像（みてみん）の一覧があります。
- **TXT の一括インポート**：なろう・アルファから出力した TXT を、章・話に分けて取り込みます（UTF-8・Shift_JIS）。
- **自動保存と版**：ブラウザ内に自動保存します。エピソードの版と作品全体のバックアップ版も残ります。
- **ファイル**：全体（全作品）とエピソードの保存・開く、プレーンテキストの読み込み・書き出しができます。保存先は Google ドライブか、この端末・その他（iCloud・OneDrive など）です。
- **自動バックアップと端末どうしの同期**：フォルダか Google ドライブへ、全作品を自動で保存します。起動したときは、他の端末の新しい記録を作品ごとにまとめて読み込みます。

## 動作環境

| 端末 | ブラウザ | 補足 |
|---|---|---|
| Windows・Mac | Chrome・Edge（おすすめ） | 保存先を選ぶ画面が使えます。自動バックアップの保存先に「フォルダ」も選べます |
| Mac | Safari | 保存は「ダウンロード」フォルダへ。自動バックアップは Google ドライブのみ |
| iPhone・iPad | Safari（ホーム画面に追加） | 保存は共有メニュー（「"ファイル"に保存」）。自動バックアップは Google ドライブのみ |
| Android | Chrome | 自動バックアップは「フォルダ」（端末内）か Google ドライブ |

## データの保存先とプライバシー

- 作品は**使っている端末のブラウザの中（IndexedDB）**に保存されます。サーバーには送りません。
- 外部に送るのは、自分で Google ドライブを使うと決めたときだけです。権限は `drive.file`（このアプリで作ったファイルと、自分で選んだフォルダ・ファイルだけ）です。
- iPhone・iPad では、Safari で開いたときとホーム画面のアプリで開いたときで、データが別々になります。
- ブラウザのデータを消すと、作品も消えます。**自動バックアップ**か、「ファイル」→ 全体の「名前を付けて保存」で、こまめに残してください。

## はじめかた

1. 公開した URL をブラウザで開きます。
2. （iPhone・iPad）Safari の共有 →「ホーム画面に追加」。（Android）Chrome のメニュー →「アプリをインストール」。
3. 「設定」→「自動バックアップ」で保存先を選んでおくと安心です。複数の端末で使う場合は、すべての端末で「Google ドライブ」を選びます。
4. Google ドライブを使う場合は、下の「[Google ドライブを使うための準備](#google-ドライブを使うための準備)」を最初に1回だけ行います。

## 自分で公開する（GitHub Pages）

1. このリポジトリを自分のアカウントにフォーク（またはファイルをアップロード）します。
   公開に必要なのは `index.html`、`styles.css`、`sw.js`、`manifest.webmanifest`、`js/`、`icons/` です。`docs/`・`tests/`・`tools/` は任意です。
2. **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
4. 更新したら、各端末で一度再読み込みします（ホーム画面のアプリは閉じて開き直します）。

## Google ドライブを使うための準備

最初に1回だけ必要です。Google ドライブを使わないなら不要です。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、**Google Drive API** を有効にします。
2. 「Google Auth Platform」で、次の3つを設定します。
   - アプリ名・サポートメール・対象「外部」
   - スコープ `https://www.googleapis.com/auth/drive.file`
   - テストユーザー（自分の Gmail）
3. 「クライアント」→ **ウェブ アプリケーション** を作り、次の2つを登録します。
   - **承認済みの JavaScript 生成元**：`https://<ユーザー名>.github.io`（手元で試すなら `http://localhost:8765` も）
   - **承認済みのリダイレクト URI**：公開 URL そのもの（例：`https://<ユーザー名>.github.io/<リポジトリ名>/`。最後の `/` まで同じにします。手元で試すなら `http://localhost:8765/` も）
     - ホーム画面のアプリや、ポップアップが開けないときは、ページごと Google に移動してログインし、この URI に戻ってきます。
     - 登録がないと `redirect_uri_mismatch` になります。
4. 表示された **クライアントID** を、エディターの「設定」→「クラウド」に入れて保存します。
   - すべての端末で同じクライアントID・同じ Google アカウントを使えば、どの端末で保存したファイルも、ほかの端末から開けます。
5. （任意）保存先フォルダを Google Picker で選びたい場合は、**API キー**を作り（Google Picker API を有効化）、同じ画面に入れます。

- アプリが「テスト中」の間は、約7日ごとにログインし直す必要があります。
- 1回のログインは約1時間で切れます。切れると画面の上にログインのボタンが出ます。

## 開発

### 手元で試す（Windows）

```powershell
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

- アプリ：http://localhost:8765/
- 自動テスト：http://localhost:8765/tests/index.html

### ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `styles.css` | 画面 |
| `js/app.js` | 画面の動作・自動保存・章とエピソード・ファイル・設定など |
| `js/format.js` | 作品のデータ形式（v3）・旧形式からの移行・文字数 |
| `js/notation.js` | なろう／アルファの記法と変換・挿絵・X の文字数・ひな型 |
| `js/importer.js` / `js/importui.js` | TXT インポートの解析と画面 |
| `js/tables.js` | 分類つきの表（設定・登場人物）と全体プロット |
| `js/db.js` | 端末内保存（IndexedDB） |
| `js/backup.js` / `js/sync.js` | 全体・エピソードのファイル形式と復元／自動バックアップと同期 |
| `js/localfile.js` | 端末のファイルの読み書き（保存先を選ぶ画面・共有メニュー・ダウンロード） |
| `js/dialogs.js` | 確認・入力・選択の画面（どの OS でも同じボタンの並び） |
| `js/providers/` | Google ドライブ接続 |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面アイコン |
| `docs/` | 使い方と、改修の記録 |
| `tests/` | 自動テストとサンプル TXT |

- フレームワークやビルドは使っていません。HTML・CSS・JavaScript（ES モジュール）だけで動きます。
- 更新したときは、`sw.js` の `VERSION` と `js/app.js` の `APP_VERSION` を上げてください（各端末に新しい版が届くようにするため）。
